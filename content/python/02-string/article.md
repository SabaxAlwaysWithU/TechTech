## 文字列は「文字の並んだ列」

`"こんにちは"` のような文字列は、文字が1つずつ順番に並んだものです。Python には、文字列を組み立てたり、一部を取り出したり、変換したりする道具がそろっています。

## f文字列: 変数を埋め込む

前のレッスンでは、文字列と数をつなぐのに `str()` を使いました。もっと楽なのが **f文字列** です。

```python
name = "さば"
age = 20
print(f"{name}さんは{age}歳です")
```

引用符の前に `f` を付けると、`{ }` の中に書いた変数の中身が埋め込まれます。数でも `str()` はいりません。JavaScript のテンプレート文字列(`` `${name}` ``)と同じ働きです。

`{ }` の中には計算も書けます。

```python
price = 1200
print(f"3個で{price * 3}円")
```

`:` のあとに書式を付けると、表示の形を整えられます。金額でよく使うのが3桁区切りです。

```python
total = 1234567
print(f"{total:,}円")
print(f"{3.14159:.2f}")
```

`{total:,}` は `1,234,567`、`{3.14159:.2f}` は小数点以下2桁で `3.14` になります。

## 長さと、よく使う操作

```python
word = "Python"
print(len(word))
print(word.upper())
print(word.lower())
print(word.replace("Py", "パイ"))
```

`len(...)` は文字数を返します。`文字列.upper()` のように、文字列のあとに `.` を付けて呼ぶ命令を**メソッド**と呼びます。

| 書き方 | すること | `"Python"` での結果 |
| --- | --- | --- |
| `len(s)` | 文字数 | `6` |
| `s.upper()` | 大文字にする | `PYTHON` |
| `s.lower()` | 小文字にする | `python` |
| `s.replace(a, b)` | a を b に置き換える | `s.replace("Py", "パイ")` → `パイthon` |
| `s.strip()` | 前後の空白を取る | |
| `s.split(区切り)` | 区切ってリストにする | |

メソッドは元の文字列を変えず、新しい文字列を返します。`word.upper()` のあとも `word` は `"Python"` のままです。変えたいときは `word = word.upper()` と入れ直します。

`split` は、区切り文字でばらばらにします。

```python
date = "2025-04-01"
parts = date.split("-")
print(parts)
print(parts[0])
```

`["2025", "04", "01"]` という**リスト**(レッスン4で学ぶ、値の並び)になります。`parts[0]` で最初の `"2025"` を取り出せます。

## 番号で取り出す、切り出す

文字列の中の文字には、0 から始まる番号が付いています。

```python
word = "Python"
print(word[0])
print(word[-1])
print(word[0:2])
print(word[2:])
```

- `word[0]` は最初の文字 `P`。番号は 0 から数えます
- `word[-1]` は最後の文字 `n`。マイナスは後ろから数えます
- `word[0:2]` は 0番から 2番の手前まで、つまり `Py`(**スライス**と呼びます)
- `word[2:]` は 2番から最後まで `thon`

`[開始:終わり]` の「終わり」は含まれない、と覚えてください。

## 文字列を数にする

フォームの入力やファイルから読んだ値は、数字に見えても文字列です。計算するには `int()`(整数)や `float()`(小数)で数にします。

```python
a = "1200"
b = "3"
print(a * 2)
print(int(a) * int(b))
```

1行目は文字列の `*` なので、`"1200"` を2回くり返した `12001200` になります。2行目は数どうしのかけ算で `3600` です。

`int("abc")` のように数にできない文字列を渡すと、`ValueError` というエラーになります。エラーへの対処はレッスン7で扱います。

## まとめ

- `f"...{変数}..."` で埋め込む。`{x:,}` で3桁区切り
- `len()` で文字数、`.upper()` `.replace()` `.split()` などのメソッドで加工する
- `s[0]` は最初、`s[-1]` は最後、`s[開始:終わり]` で切り出し(終わりは含まない)
- 文字列の数字は `int()` で数にしてから計算する
