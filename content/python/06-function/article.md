## レシピの「タレを作る」

レシピに毎回「醤油大さじ2、みりん大さじ1を混ぜる」と書くのは面倒です。「タレの作り方」を1か所に書いておき、「ここでタレを作る」と呼び出せば済みます。

ひとまとまりの処理に名前を付け、名前で呼び出せるようにしたものが**関数**です。`print` や `len` も、Python が最初から用意している関数です。

## def で作る、名前で呼ぶ

```python
def greet():
    print("こんにちは")
    print("ようこそ")

greet()
greet()
```

`def 名前():` で関数を作ります(**定義**)。`if` と同じく、行の終わりに `:` を付け、中身を字下げします。作っただけでは何も起きず、`greet()` と書いたときに中身が実行されます(**呼び出し**)。2回呼んでいるので4行表示されます。

## 引数で値を渡す

```python
def greet(name):
    print(f"こんにちは、{name}さん")

greet("さば")
greet("たら")
```

カッコの中の `name` が**引数**です。`greet("さば")` と呼ぶと、`name` に `"さば"` が入った状態で中身が動きます。カンマで区切れば、いくつでも受け取れます。

## return で結果を返す

関数は、計算した結果を呼び出した側に返せます。

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
print(add(10, 20) * 2)
```

`add(3, 4)` は `7` という値になり、`result` に入ります。返ってきた値は、そのまま計算にも使えます。

`print` と `return` の違いは大事です。

- `print` は出力欄に**表示する**だけ。呼び出した側には何も渡らない
- `return` は呼び出した側に**値を返す**。表示はしない

`return` を書かない関数は `None` を返します。「関数を作ったのに結果が `None` になる」ときは、`print` だけして `return` を忘れていることがほとんどです。

`return` を実行すると、関数はそこで終わります。条件に合ったら早めに返す書き方もよくします。

```python
def sign(n):
    if n > 0:
        return "プラス"
    if n < 0:
        return "マイナス"
    return "ゼロ"

print(sign(-5))
```

## 引数の決まった値

引数には、渡されなかったときの値(**デフォルト値**)を決めておけます。

```python
def with_tax(price, rate=10):
    return price * (100 + rate) // 100

print(with_tax(1000))
print(with_tax(1000, 8))
print(with_tax(1000, rate=8))
```

`rate=10` と書いておくと、`with_tax(1000)` のように省略したときは 10 が使われます。最後の行のように `名前=値` で渡すと、どの引数に渡したのかが読む人にもわかりやすくなります。

## 関数の中の変数は、中だけのもの

```python
def calc():
    tax = 100
    return tax

calc()
print(tax)
```

関数の中で作った変数は、関数の外からは見えません。この例は `NameError: name 'tax' is not defined` になります。関数の結果を外で使いたいときは、`return` で返して変数に受け取ります。

## 関数を使う理由

- **同じ処理を1か所にまとめられる**: 直すときも1か所で済む
- **名前が説明になる**: `with_tax(price)` とあれば、中を読まなくても何をするかわかる
- **分けて考えられる**: 大きな処理を、小さな関数の組み合わせにできる

## まとめ

- `def 名前(引数):` で作り、中身を字下げする。`名前(値)` で呼び出す
- `return` で結果を返す。`print` は表示するだけで、値は返さない
- `return` がないと `None` が返る
- `引数=値` でデフォルト値を決められる。関数の中の変数は外から見えない
