## 頼まれごと

学校の先生から、テストの成績処理を Python で手伝ってほしいと頼まれました。お願いは5つです。

1. 「80,欠席,95」のような点数のメモを、数のリストにする(欠席は 0 点)
2. 1人の生徒の合計点を出す
3. 合計点が合格ライン以上の生徒の名前を集める
4. クラスごとに、合計点の平均を出す
5. 合計点の上位3人を「1位 鈴木 270点」の形で表示する

練習場の5つの課題が、この5つです。1〜4は「関数を1つ作る」課題で、関数を呼んだ結果で判定します。5は表示した内容で判定します。

## 使う知識

| 頼まれごと | 使うもの | レッスン |
| --- | --- | --- |
| 1 メモを数にする | `split`、`int`、`try` / `except` | 文字列、エラーと例外 |
| 2 合計点 | 辞書の `values()`、`sum` | 辞書 |
| 3 合格者 | `for`、`if`、`append` | リストと繰り返し、条件分岐 |
| 4 クラスの平均 | 辞書で集計する | 辞書、関数 |
| 5 上位3人 | `sorted` の `key`、f文字列 | 並べ替え、文字列 |

## 成績のデータ

生徒1人が1つの辞書で、`scores` の中にさらに教科ごとの点数の辞書が入っています。辞書の中に辞書がある形です。

```python
students = [
    {"name": "山田", "class": "A", "scores": {"国語": 80, "数学": 92, "英語": 78}},
    {"name": "佐藤", "class": "B", "scores": {"国語": 65, "数学": 70, "英語": 88}},
]
s = students[0]
print(s["name"])
print(s["scores"]["数学"])
```

`s["scores"]` で点数の辞書が取り出せるので、続けて `["数学"]` と書けば 92 になります。

## 関数を組み合わせる

課題3〜5では、課題2で作る「合計点の関数」を中で呼ぶと短く書けます。

```python
def total_score(student):
    return sum(student["scores"].values())

def is_passed(student, line):
    return total_score(student) >= line
```

1つの関数に全部を詰め込まず、役割ごとに小さな関数に分けると、1つずつ確かめられます。課題3と5の初期状態には、課題2の関数を入れてあります。

## 並べ替えの順番を決める: sorted の key

課題5では、レッスン「並べ替え」の `sorted` の `key` を使います。`key=` には、比べる値を返す関数を渡すのでした。

```python
words = ["バナナ", "も", "りんご"]
print(sorted(words, key=len, reverse=True))
```

課題2で作る `total_score` も関数なので、そのまま渡せます。`sorted(students, key=total_score, reverse=True)` で合計点の高い順になり、上位3人はそのリストの `[:3]` です。`lambda` を使って `key=lambda s: total_score(s)` と書いても同じです。

## 詰まったら

- まず `print` で途中の値を表示して、思った値になっているか確かめる
- 判定のメッセージに「あなた: ○○、期待: △△」と出るので、どこが違うかを比べる
- エラーが出たら、出力欄の行番号と最後の行を読む(レッスン「エラーと例外」)
