## Python はどんな言語か

Python(パイソン)は、**読みやすさ**を大事にして作られたプログラミング言語です。同じ処理でも記号が少なく、英語の文章に近い形で書けます。

使われる場面は広く、データの集計やグラフ作り、AI・機械学習、Webアプリのサーバー側、仕事の自動化(ファイルの整理やメールの送信)などがあります。

JavaScript がブラウザの中で動く言語だとすると、Python は「パソコンやサーバーの上で、裏方の仕事をする」ことが多い言語です。この練習場では、ブラウザの中で本物の Python を動かします。

## print で表示する

```python
print("こんにちは")
print("Python へようこそ")
```

`print(...)` はカッコの中を出力欄に表示する命令です。1回で1行表示されます。

文字は `"` か `'` で囲みます。囲んだものを**文字列**と呼びます。JavaScript と違い、行の終わりに `;` は書きません。

`#` から行の終わりまでは**コメント**で、Python は読み飛ばします。メモを残すのに使います。

```python
# これはコメント。実行されない
print("表示される")  # 行の途中からでも書ける
```

## 計算する

```python
print(12 + 34)
print(10 - 3)
print(6 * 7)
print(7 / 2)
```

`*` がかけ算、`/` が割り算です。数は `"` で囲みません。囲むと文字列になり、計算されずにそのまま表示されます。

`7 / 2` は `3.5` になります。割り算の結果は、割り切れても小数になります(`6 / 2` は `3.0`)。

ほかにもよく使う計算があります。

| 書き方 | 意味 | 例 | 結果 |
| --- | --- | --- | --- |
| `//` | 割り算の整数の部分 | `7 // 2` | `3` |
| `%` | 割り算の余り | `7 % 2` | `1` |
| `**` | べき乗 | `2 ** 3` | `8` |

`%` は「偶数か奇数か」(2で割った余りが0か)を調べるときによく使います。

## 変数に入れる

計算の結果や文字列には、名前を付けて覚えておけます。これが**変数**です。

```python
price = 1200
count = 3
total = price * count
print(total)
```

`名前 = 値` で、右の値を左の名前の箱に入れます(**代入**)。JavaScript の `let` や `const` のような宣言はいりません。初めて代入したときに箱ができます。

もう一度代入すると、中身が入れ替わります。

```python
score = 70
score = score + 10
print(score)
```

2行目は「今の `score` に 10 を足して、`score` に入れ直す」という意味です。結果は `80` です。`score += 10` と短く書くこともできます。

変数の名前には英字、数字、`_` を使います。2語以上は `unit_price` のように `_` でつなぐのが Python の習慣です。

## 文字列と数は別物

```python
print("12" + "34")
print(12 + 34)
```

1行目は文字列どうしの `+` なので、つなげて `1234` になります。2行目は数の足し算で `46` です。見た目が同じ「12」でも、`"` で囲んだかどうかで別のものになります。

文字列と数をそのまま `+` でつなぐと、エラーになります。

```python
age = 20
print("年齢は" + age)
```

`TypeError: can only concatenate str (not "int") to str`(文字列には文字列しかつなげられない)と表示されます。数を文字列にする `str(age)` を使うか、次のレッスンの f文字列 を使います。

```python
age = 20
print("年齢は" + str(age) + "歳")
```

`print` にカンマで区切って渡すと、間にスペースを入れて並べてくれます。

```python
print("年齢は", 20, "歳")
```

## まとめ

- `print(...)` で出力欄に表示する。文字列は `"` で囲む
- `+ - * /` のほか、`//`(整数の割り算)、`%`(余り)、`**`(べき乗)
- `名前 = 値` で変数に代入する。宣言はいらない
- 文字列と数は `+` でつなげない。`str(数)` で文字列にする
