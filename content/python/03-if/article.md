## 「もし雨なら傘を持つ」

毎朝「もし雨なら傘を持つ、そうでなければ持たない」と決めているように、プログラムも条件によって動きを変えられます。これが**条件分岐**です。

## if と字下げ

```python
temperature = 32
if temperature >= 30:
    print("暑いので水を持っていこう")
print("いってきます")
```

`if 条件:` の次の行から、**字下げ(インデント)した行**が「条件が成り立つときにだけ実行する部分」です。上の例では 32 は 30 以上なので両方表示されます。`temperature` を 20 にすると「いってきます」だけになります。

ここが Python のいちばんの特徴です。JavaScript では `{ }` でかたまりを囲みましたが、Python は**字下げの深さ**でかたまりを表します。

- `if` の行の終わりには `:`(コロン)を付ける
- かたまりの中の行は、スペース4つで字下げする(この練習場では Tab キーで入ります)
- 字下げをやめた行から、かたまりの外に戻る

字下げは見た目のためではなく、文法の一部です。ずれていると `IndentationError` というエラーになります。

## else と elif

```python
score = 75
if score >= 80:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
```

- `else:` は「どの条件にも当てはまらなかったとき」
- `elif 条件:` は「else if」の短縮形で、条件をいくつも並べられる

上から順に調べ、最初に当てはまったところだけを実行して終わります。75 は 80 以上ではなく、60 以上なので `B` です。そのため、厳しい条件(80 以上)を先に書くのがコツです。

## 比べる記号

| 記号 | 意味 |
| --- | --- |
| `==` | 等しい |
| `!=` | 等しくない |
| `>` `<` | より大きい、より小さい |
| `>=` `<=` | 以上、以下 |

等しいかどうかは `==` です。`=` は代入なので、`if x = 1:` と書くとエラーになります。

比べた結果は `True`(正しい)か `False`(正しくない)のどちらかです。これを**真偽値**と呼びます。先頭は大文字で書きます。

```python
print(5 > 3)
print(5 == 3)
```

## and、or、not

条件を組み合わせるときは英単語を使います。JavaScript の `&&` `||` `!` にあたります。

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("入場できます")

if age < 6 or age >= 65:
    print("割引があります")

if not has_ticket:
    print("チケットを買ってください")
```

- `A and B`: A も B も成り立つとき
- `A or B`: A か B のどちらかが成り立つとき
- `not A`: A が成り立たないとき

`18 <= age < 65` のように、比べる記号を続けて書くこともできます。「18 以上 65 未満」をそのまま書けるのは Python の便利なところです。

## まとめ

- `if 条件:` の次の行から、字下げした部分が条件付きで実行される
- 字下げはスペース4つ。Python は字下げでかたまりを表す
- `elif` で条件を足し、`else` で残りすべて。上から順に調べる
- 等しいは `==`、組み合わせは `and` `or` `not`
