## 買い物メモ

「牛乳、卵、パン」と1枚のメモに並べて書くように、たくさんの値を1つにまとめて持てるのが**リスト**です。そして「メモの上から順に1つずつカゴに入れる」のが**繰り返し**です。この2つはいつも一緒に使います。

## リストを作る

```python
fruits = ["りんご", "バナナ", "みかん"]
print(fruits[0])
print(fruits[-1])
print(len(fruits))
```

`[ ]` の中に値をカンマで並べます。取り出し方は文字列と同じで、番号は 0 から、`-1` は最後です。`len()` で個数がわかります。

リストはあとから変えられます。

```python
fruits = ["りんご", "バナナ"]
fruits.append("みかん")
fruits[0] = "ぶどう"
print(fruits)
print("バナナ" in fruits)
```

- `リスト.append(値)` で最後に1つ足す
- `リスト[番号] = 値` でその場所を入れ替える
- `値 in リスト` で、入っているかどうかを `True` / `False` で調べる

## for で1つずつ取り出す

```python
fruits = ["りんご", "バナナ", "みかん"]
for fruit in fruits:
    print(f"{fruit}を買う")
print("買い物終わり")
```

`for 変数 in リスト:` と書くと、リストの先頭から1つずつ変数に入れて、字下げした部分をくり返します。上の例では `fruit` に `"りんご"`、`"バナナ"`、`"みかん"` が順に入り、3回まわります。字下げしていない最後の行は、くり返しが終わってから1回だけ実行されます。

## range で回数を決める

「5回くり返す」のように回数で回したいときは `range` を使います。

```python
for i in range(5):
    print(i)

for i in range(1, 4):
    print(f"{i}回目")
```

- `range(5)` は 0, 1, 2, 3, 4(5は含まない)
- `range(1, 4)` は 1, 2, 3(終わりは含まない)

スライスと同じく「終わりは含まない」です。JavaScript の `for (let i = 0; i < 5; i++)` が、Python では `for i in range(5):` の1行になります。

## 集めて計算する

くり返しの中で、変数に足し込んでいく書き方はよく使います。

```python
prices = [1200, 800, 3500]
total = 0
for price in prices:
    total += price
print(total)
```

`total` を 0 で用意し、1つずつ足していきます。最後の `print` は字下げしていないので、足し終わってから表示されます。

よく使う計算は、最初から用意されています。

| 書き方 | 結果(`[1200, 800, 3500]`) |
| --- | --- |
| `sum(prices)` | 合計 `5500` |
| `max(prices)` | いちばん大きい `3500` |
| `min(prices)` | いちばん小さい `800` |
| `sorted(prices)` | 小さい順に並べた新しいリスト |

条件に合うものだけを集めるときは、空のリストに `append` していきます。

```python
scores = [45, 80, 62, 90, 30]
passed = []
for s in scores:
    if s >= 60:
        passed.append(s)
print(passed)
```

`if` が `for` の中にあるので、字下げが2段になっています。

## while: 条件が続くあいだくり返す

```python
money = 1000
while money >= 300:
    money -= 300
    print(f"300円使った。残り{money}円")
```

`while 条件:` は、条件が `True` のあいだくり返します。条件がずっと `True` のままだと終わらなくなる(**無限ループ**)ので、中で条件が変わるようにしておきます。リストを順に処理するなら、たいていは `for` で足ります。

## まとめ

- `[a, b, c]` でリストを作る。`append` で足し、`in` で調べる
- `for 変数 in リスト:` で1つずつ取り出してくり返す
- `range(n)` で n 回。終わりの数は含まない
- `sum` `max` `min` `sorted` が使える。条件に合うものは空のリストに `append` して集める
