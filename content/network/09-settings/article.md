## 設定画面の4つの欄

Windows でも Mac でも、ネットワークの詳しい設定を開くと、だいたい同じ4つの欄があります。

| 欄 | 意味 | 家庭のふつうの値 |
| --- | --- | --- |
| **IPアドレス** | 自分の住所 | 192.168.1.10 |
| **サブネットマスク** | どこまでが「同じネットワーク(家の中)」か | 255.255.255.0 |
| **デフォルトゲートウェイ** | 家の外に出るときの出入口(ルーター) | 192.168.1.1 |
| **DNSサーバー** | 名前を住所に変えてくれる電話帳 | 8.8.8.8 など |

ふだんは「**自動(DHCP)**」になっていて、ルーターが4つとも配ってくれます。「**手動**」にすると自分で書き込めます。練習場の左に、この設定画面を置いてあります。

## サブネットマスク: 同じネットワークかどうか

サブネットマスクは少し分かりにくいので、ここだけ詳しく説明します。

`255.255.255.0` は、「最初の3つの数が同じ相手は、同じネットワークにいる」という意味です。

```
自分       192.168.1.10
ルーター    192.168.1.1     ← 最初の3つ(192.168.1)が同じ → 家の中
サーバー    93.184.216.34   ← 違う → 家の外
```

PC はパケットを送るたびに、この判断をしています。

- **同じネットワーク**の相手には、ケーブルの先に直接呼びかける
- **違うネットワーク**の相手には、とにかくゲートウェイに渡して「外へお願いします」と頼む

`/24` という書き方も同じ意味です(255.255.255.0 の「1」の数が24個)。`ip addr` で `192.168.1.10/24` と出ていたのはこれです。

## 打ち間違えると、こうなる

4つの欄のどれを間違えたかで、壊れ方がきれいに分かれます。練習場で実際に打ち込んで試せます。

**ゲートウェイを間違える(192.168.1.254 など、誰もいない番号)**
家の中のルーター(`ping 192.168.1.1`)には届くのに、外(`ping 8.8.8.8`)には `Destination Host Unreachable`。PC は「外へお願いします」と 192.168.1.254 さんに呼びかけますが、誰も応えません。

**DNS を間違える(192.168.1.99 など)**
`ping 8.8.8.8` は通るのに、`nslookup example.com` は `connection timed out`。電話帳の番号を間違えているだけで、道はつながっています。

**IPアドレスを違うネットワークにする(192.168.2.10 など)**
ルーター(192.168.1.1)が「自分と違うネットワーク」に見えてしまい、しかもゲートウェイ(192.168.1.1)も同じネットワークにいないので、どこにも送れません。`Network is unreachable`。

**IPアドレスをルーターと同じにする(192.168.1.1)**
同じ住所が2つある**IPアドレスの競合**です。`ip addr` に `dadfailed`(重複を検知した)と出て、外とは通信できません。Windows なら「IPアドレスの競合が検出されました」と通知が出ます。

引っかけが1つあります。この状態で `ping 192.168.1.1` を打つと、**通ってしまいます**。ルーターではなく、同じ番号を持つ自分自身に返事をしているだけです。`time=0.1 ms` のように異様に速いのが目印です。「ping が通ったから大丈夫」とは限りません。

**サブネットマスクを書き間違える(255.255.0.255 など)**
マスクは左から 255 が続き、途中から 0 になる形しかありません。おかしな値だと IP そのものが使えなくなります。

## 自分で直す: 2つの定番

設定を知っていると、「壊れた部品を直せない」ときにも逃げ道を作れます。

**DHCP が壊れて IP がもらえない → 手動で設定する**
ルーターの DHCP が動かなくても、空いている番号(192.168.1.50 など)、マスク、ゲートウェイ、DNS を自分で書けば通信できます。DHCP は「配ってくれる係」で、道そのものではないからです。

**DNS サーバーが落ちた → 別の DNS に切り替える**
8.8.8.8(Google)が応えないなら、1.1.1.1(Cloudflare)に変えれば名前が引けます。DNS サーバーは世界にいくつもあり、どれを使うかは自分で選べます。

## まとめ

- 設定は4つ: IPアドレス、サブネットマスク、デフォルトゲートウェイ、DNSサーバー。ふだんは DHCP が自動で配る
- サブネットマスクで「同じネットワークか」を決め、外の相手はゲートウェイに渡す
- ゲートウェイの間違い → 外だけ届かない。DNS の間違い → 名前だけ引けない。IP の間違い → どこにも届かない
- DHCP が壊れたら手動で、DNS が落ちたら別の DNS に切り替えて逃げられる
