## 「インターネットが使えない」

社内のヘルプデスクに、朝から「つながらない」という連絡が4件届きました。今日は、図の部品に「正常 / 故障」が表示されません(全部「?」です)。コマンドの結果だけを手がかりに、どこが壊れているかを当てて直してください。

1. 「何も開けない」
2. 「サイトは開けないし、開けても商品一覧がエラーになる」
3. 「HTTPS のページで警告が出る。無視して進んでも商品一覧が出ない」
4. 「設定を自分でいじってから、つながらなくなった」

2〜4は、壊れているところが2か所あります。1つ直すとエラーの文言が変わるので、それを手がかりに次を探します。

## 下から順に調べる

つながらないときは、近いところから遠いところへ、1段ずつ確かめます。

| 段 | 確かめるコマンド | 通らないときに疑うところ |
| --- | --- | --- |
| 1. 自分の PC | `ip addr` | IPアドレスの設定、ケーブル |
| 2. 家の出口 | `ping 192.168.1.1` | ケーブル、ルーター、設定のゲートウェイ |
| 3. インターネット | `ping 8.8.8.8`、`traceroute 8.8.8.8` | インターネット回線 |
| 4. 名前を引く | `nslookup example.com` | DNS |
| 5. Web サーバー | `curl http://example.com/` | サーバー、ポート、証明書、アプリ、データベース |

## エラーの文言は手がかり

これまでのレッスンで見てきた文言が、そのまま手がかりになります。

- `Network is unreachable`: そもそも外へ出る道がない(ケーブルや設定)
- `Destination Host Unreachable`: 相手が見つからない(ルーターや、ゲートウェイの番号の誤り)
- `Could not resolve host`: 名前が引けない(DNS、またはそこまで届いていない)
- `Connection refused`: サーバーには届いたが、入口(ポート)が閉じている
- `certificate has expired`: 証明書の期限切れ
- `502 Bad Gateway`: nginx の後ろのアプリが止まっている
- `ECONNREFUSED 127.0.0.1:5432`: アプリの後ろのデータベースが止まっている

## 直し方

部品の故障は、図の部品(または右の部品一覧)を押して直します。設定の誤りは、上の設定画面で正しい値に直して「適用」します。正しい設定は、IPアドレス `192.168.1.10`、マスク `255.255.255.0`、ゲートウェイ `192.168.1.1`、DNS `8.8.8.8` です。

全部直したら、最後に依頼と同じ `curl` でページが取れることを確かめましょう。
