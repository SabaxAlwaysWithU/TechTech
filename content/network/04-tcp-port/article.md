## 住所だけでは足りない

手紙がマンションに届いても、「何号室の誰宛てか」が書いていなければ渡せません。IPアドレスで**コンピュータ**までは届きますが、そのコンピュータの中では、Webサーバー、メールサーバー、DNS など複数のプログラムが待っています。どのプログラムに渡すかを決める番号が**ポート**です。

| ポート | 待っているもの |
| --- | --- |
| 80 | Web(HTTP) |
| 443 | Web(HTTPS) |
| 53 | DNS |
| 22 | SSH(遠隔操作) |
| 25、587 | メール送信 |

`http://example.com/` と書くと、ブラウザは黙って 80 番に、`https://` なら 443 番につなぎに行きます。`nslookup` の結果にあった `#53` は、DNS の 53 番を指していました。

ポートは 0〜65535 まであり、よく使うものは上のように決まっています。自分でサーバーを作るときは `3000` や `8080` のような空いている番号を使います(Webアプリの道具分野の `localhost:3000` がそれです)。

## 「開いている」「閉じている」

サーバー側では、プログラムが「80番で待っています」と宣言して初めて、その番号が**開き**ます。プログラムが動いていない、または**ファイアウォール**(通していい番号のリスト)で塞がれていると、その番号は**閉じて**います。

閉じたポートにつなぎに行くと、こう返ります。

```
curl: (7) Failed to connect to example.com port 80: Connection refused
```

「接続を拒否された」。大事なのは、**サーバーのコンピュータ自体は生きていて、返事をしている**ことです。「80番には誰もいません」と即座に教えてくれています。実際、同じ状態で `ping example.com` は普通に通ります。

これと、サーバーの電源が落ちているときの違いを見比べてください。

```
curl: (28) Failed to connect to example.com port 80 after 30000 ms: Connection timed out
```

こちらは「時間切れ」。コンピュータごといないので、誰も返事をせず、30秒待ってあきらめます。`ping` も `100% packet loss` になります。

| 症状 | 意味 | ping は |
| --- | --- | --- |
| `Connection refused` | コンピュータは生きているが、その番号で誰も待っていない | 通る |
| `Connection timed out` | コンピュータまで届かない、または落ちている | 通らない |

「すぐ断られる」か「待たされて失敗する」か。この違いで、サーバー側の問題かネットワークの問題かを切り分けられます。

## TCP: 確実に届ける約束

パケットは途中で消えたり、順番が入れ替わったりすることがあります。Webページが途中で欠けたら困るので、**TCP** という決まりで「確実に、順番通りに」届けます。

TCP は、データを送る前に**3回のやりとりで接続を作ります**(3ウェイハンドシェイク)。

```
PC     →  サーバー   「つなぎたい」(SYN)
PC     ←  サーバー   「いいよ、そっちも準備OK?」(SYN-ACK)
PC     →  サーバー   「OK」(ACK)
```

このあと初めてデータが流れます。`Connection refused` は1回目に「だめ」と返された状態、`timed out` は1回目に誰も答えない状態です。

送ったパケットには番号が付いていて、相手は「ここまで受け取った」と返事をします。返事がなければ送り直す。だから欠けません。

## UDP: 速さ優先

確認をしない代わりに速い **UDP** という決まりもあります。多少欠けても困らない動画のストリーミング、音声通話、ゲーム、そして DNS の問い合わせが UDP を使います。「確実な TCP、速い UDP」と覚えてください。

## まとめ

- IPアドレスでコンピュータまで、ポート番号でその中のプログラムまで届く
- 80 は HTTP、443 は HTTPS、53 は DNS
- `Connection refused` は番号が閉じている(コンピュータは生きている)。`timed out` はコンピュータまで届かない
- TCP は3回のやりとりで接続を作り、番号を付けて確実に届ける。UDP は速さ優先
