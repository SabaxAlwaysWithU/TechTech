## 今日からデータ係

あなたはネットショップのデータ係になりました。初日、店長から付箋が5枚届きます。

1. 「商品のカテゴリごとに、何種類あって、一番高いのはいくらか知りたい」
2. 「お客さんが2人以上いる都道府県はどこ?」
3. 「よく売れている商品トップ3を教えて。キャンセルされた注文は数えないでね」
4. 「たくさん買ってくれたお客さんトップ3に、お礼の手紙を書きたい」
5. 「10月15日までの準備中の注文、さっき全部発送したから、記録を直しておいて」

どれも、これまでのレッスンの組み合わせで書けます。練習場の5つの課題が、この5枚の付箋です。

## 書く前に考えること

付箋の言葉を、SQL の部品に置き換えてから書き始めると迷いません。

- 「〜ごとに」→ `GROUP BY`(集計)
- 「〜が2人以上の」のように、まとめた結果で絞る → `HAVING`。まとめる前に1行ずつ絞るなら `WHERE`
- 「どの商品か」「誰の注文か」のように、別の表の情報がいる → `JOIN`。どの列とどの列でつなぐかを先に決める
- 「トップ3」→ `ORDER BY ... DESC` と `LIMIT 3`
- 「記録を直す」→ `UPDATE`。`WHERE` を付け忘れると全部の行が変わるので、先に同じ条件の `SELECT` で対象を確かめる

## 表のおさらい

| 表 | 中身 | つなぐ列 |
| --- | --- | --- |
| `products` | 商品(名前、カテゴリ、価格) | `id` |
| `customers` | 顧客(名前、都道府県) | `id` |
| `orders` | 注文(誰が、いつ、状態) | `customer_id` → `customers.id` |
| `order_items` | 注文の明細(どの商品を何個) | `order_id` → `orders.id`、`product_id` → `products.id` |

売上の金額は、`order_items.quantity`(個数)× `products.price`(価格)で求めます。注文の状態(`status`)は「発送済」「準備中」「キャンセル」の3つです。

## 進め方のコツ

いきなり完成形を書かず、少しずつ足していきます。たとえば付箋3なら、

1. `order_items` と `products` をつないで、明細に商品名が付くのを確かめる
2. `orders` もつないで、`WHERE` でキャンセルを外す
3. `GROUP BY` で商品ごとにまとめ、`SUM(quantity)` で個数を足す
4. 最後に並べ替えて3つに絞る

という順です。途中で結果を見ながら進めれば、どこで間違えたかがすぐ分かります。

分からなくなったら、該当するレッスン(「集計」「JOIN」「データの変更」)に戻って構いません。
