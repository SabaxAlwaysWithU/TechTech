## ずらすと、2倍や半分になる

10進数で、数を左へ1けたずらす(右に 0 を付ける)と10倍になります。352 → 3520 です。2進数では、**左へ1けたずらすと2倍**になります。

```text
0000 0011  (3)
  ↓ 左へ1つずらす
0000 0110  (6)
  ↓ もう1つ
0000 1100  (12)
```

逆に、**右へ1けたずらすと半分**になります。はみ出した右端のビットは捨てられるので、奇数なら小数点以下が切り捨てられます(7 → 3)。

この「ずらす」操作を**シフト**といいます。C では `x << 1`(左へ)、`x >> 1`(右へ)と書きます。コンピュータにとって、ずらすのは掛け算や割り算よりずっと簡単なので、2倍、4倍、半分…の計算は昔からシフトで速く行われてきました。左へずらしすぎると、左端からビットがあふれて消えるのは、前のレッスンのオーバーフローと同じです。

## 反転: 0 と 1 を入れ替える

全部のビットの 0 と 1 を入れ替える操作が**反転**(NOT、C では `~x`)です。前のレッスンで見たように、2の補数で符号を逆にするときに使います。

## ビットを、スイッチの並びとして使う

ビットの並びは、数としてだけでなく、「**いくつかのスイッチのオン / オフ**」をまとめて持つのにも使われます。1ビットに1つの意味を決めておけば、8つのオン / オフを1バイトで持てます。

その代表が、OS の分野で見た**ファイルの権限**です。`rwxr-xr-x` は、9個のスイッチの並びです。

| | 持ち主 | グループ | ほかの人 |
| --- | --- | --- | --- |
| 権限 | `rwx` | `r-x` | `r-x` |
| ビット | 1 1 1 | 1 0 1 | 1 0 1 |
| 8進数 | 7 | 5 | 5 |

r(読む)が 4、w(書く)が 2、x(実行する)が 1 の重みで、3ビットずつを1つの数字にしたのが `chmod 755` の **755** です。3ビットで 0〜7 の8通りなので、これは**8進数**です。16進数が4ビットずつの書き方だったのと同じ考え方です。

## AND と OR: 1つのスイッチだけを見る、変える

スイッチの並びから、1つだけを調べたり変えたりするときは、ビットごとの計算を使います。

- **AND**(`&`): 両方が 1 のビットだけ 1 になる。「このスイッチは入っているか」を調べるのに使う(`権限 & 4` が 0 でなければ、読める)
- **OR**(`|`): どちらかが 1 なら 1 になる。「このスイッチを入れる」のに使う(`権限 | 2` で、書ける を足す)

```text
  1 0 1   (r-x)          1 0 1   (r-x)
& 1 0 0   (r を調べる)   | 0 1 0   (w を足す)
-------                  -------
  1 0 0   → 0 ではない   1 1 1   (rwx)
            ので読める
```

ゲームのキャラクターの状態(毒、まひ、眠り…)や、キーボードの Shift / Ctrl / Alt を押しているかなど、オン / オフの組み合わせは、あちこちでこうしてビットで持たれています。

## まとめ

- 左へ1つずらす(`<<`)と2倍、右へ1つずらす(`>>`)と半分(切り捨て)
- 反転(`~`)は 0 と 1 を入れ替える
- ビットの並びは、オン / オフのスイッチの集まりとしても使う。ファイルの権限 755 は、3ビットずつの8進数
- 1つのスイッチを調べるのは AND(`&`)、入れるのは OR(`|`)
