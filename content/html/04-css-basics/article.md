## 役割と見た目を分ける

HTMLは「ここは見出し」「ここは段落」という役割を書くものでした。では、見出しを緑にしたい、文字を大きくしたいときはどうするのでしょう。

それを決めるのが **CSS** です。HTMLが骨組みなら、CSSは服です。同じ骨組みでも、CSSを変えれば見た目はまったく別物になります。

## 書く場所

CSSは `style` 要素の中に書きます。`head` の中に置くのが普通ですが、練習場では `body` の中でも動きます。

```html
<style>
  h1 {
    color: green;
  }
</style>
<h1>今日の献立</h1>
```

これで `h1` の文字が緑になります。

## セレクタとプロパティ

CSSの1まとまりは、この形です。

```css
セレクタ {
  プロパティ: 値;
}
```

- **セレクタ**: どの要素に適用するか。上の例では `h1`
- **プロパティ**: 何を変えるか。上の例では `color`(文字色)
- **値**: どう変えるか。上の例では `green`

プロパティは `;` で区切って、いくつでも並べられます。

```css
h1 {
  color: green;
  font-size: 32px;
}
```

## よく使うプロパティ

| プロパティ | 意味 | 値の例 |
| --- | --- | --- |
| `color` | 文字色 | `red`、`#1f7a5c` |
| `background-color` | 背景色 | `yellow`、`#f6f6f6` |
| `font-size` | 文字の大きさ | `20px`、`1.5rem` |
| `font-weight` | 太さ | `bold`、`normal` |
| `text-align` | 文字の寄せ | `center`、`right` |

色は `red` のような名前のほか、`#1f7a5c` のような**16進数**でも書けます。`#` のあとの6桁が、赤・緑・青の強さを2桁ずつ表しています。

## 要素以外を選ぶ: class と id

`p { color: red; }` と書くと、**すべての**段落が赤になります。特定の段落だけ変えたいときは、HTML側に**class** という目印を付け、CSSではその名前で選びます。

```html
<style>
  .note {
    background-color: #fff3cd;
  }
</style>
<p>普通の段落です。</p>
<p class="note">この段落だけ背景が付きます。</p>
```

CSSでは class 名の前に `.`(ピリオド)を付けます。同じ class は何か所にでも付けられます。

ページに1つしかないものには `id` を使います。CSSでは `#` を付けます。

```html
<style>
  #title {
    text-align: center;
  }
</style>
<h1 id="title">中央に寄ります</h1>
```

迷ったら class を使ってください。id は「1ページに1つだけ」という制約があるので、使いどころが限られます。

## 複数の要素をまとめて選ぶ

同じ指定をいくつかの要素に付けたいときは、セレクタをカンマで並べます。

```css
h1, h2, h3 {
  color: #1f7a5c;
}
```

## まとめ

- CSSは `style` 要素の中に `セレクタ { プロパティ: 値; }` の形で書く
- 要素名で選ぶと、その要素すべてに適用される
- 一部だけ変えたいときは class を付け、CSSでは `.名前` で選ぶ
- `color`、`background-color`、`font-size` から覚える
