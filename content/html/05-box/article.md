description: "ボックスモデル: padding、border、margin"

## すべての要素は四角い箱

額縁に入った絵を思い浮かべてください。絵そのものがあり、その周りに台紙の余白があり、額縁があり、額縁と壁の他の絵との間にも空きがあります。

Webページの要素も同じ作りです。`h1` も `p` も `div` も、ブラウザの中ではすべて**四角い箱**として扱われ、中身の周りに3種類の空きを持っています。これを**ボックスモデル**と言います。

```
┌─ margin(外側の余白)───────────────┐
│  ┌─ border(枠線)───────────────┐  │
│  │  ┌─ padding(内側の余白)──┐  │  │
│  │  │       中身            │  │  │
│  │  └───────────────────────┘  │  │
│  └─────────────────────────────┘  │
└───────────────────────────────────┘
```

- **padding**: 中身と枠線の間。台紙の余白
- **border**: 枠線。額縁
- **margin**: 枠線の外側。隣の箱との距離

## 枠線を付けて確かめる

箱の形は、枠線を付けるとよく分かります。

```html
<style>
  .box {
    border: 2px solid #1f7a5c;
  }
</style>
<p class="box">この段落は箱です。</p>
```

`border` には「太さ 種類 色」を空白区切りで一度に書けます。種類は `solid`(実線)のほか `dashed`(破線)、`dotted`(点線)があります。

## 内側の余白: padding

枠線を付けると、文字が枠にぴったりくっついて窮屈に見えます。`padding` で内側に余白を取ります。

```html
<style>
  .box {
    border: 2px solid #1f7a5c;
    padding: 16px;
  }
</style>
<p class="box">余白ができて読みやすくなりました。</p>
```

`padding: 16px` は上下左右すべて16pxです。上下と左右で変えたいときは `padding: 8px 16px`(上下 8px、左右 16px)のように2つ書きます。

## 外側の余白: margin

隣の要素との距離は `margin` で取ります。

```html
<style>
  .box {
    border: 2px solid #1f7a5c;
    padding: 16px;
    margin: 24px;
  }
</style>
<p class="box">1つ目の箱</p>
<p class="box">2つ目の箱</p>
```

`padding` は箱の背景色が付く範囲ですが、`margin` には背景色が付きません。「背景を広げたいなら padding、距離を取りたいなら margin」と覚えてください。

## 幅: width

箱の横幅は `width` で決めます。何も指定しなければ、`p` や `div` は親の幅いっぱいに広がります。

```html
<style>
  .box {
    width: 300px;
    border: 2px solid #1f7a5c;
    padding: 16px;
  }
</style>
<p class="box">幅300pxの箱</p>
```

幅を決めた箱を中央に置きたいときは、`margin: 0 auto`(上下 0、左右は自動)と書きます。左右の余白が自動で等しくなり、中央に寄ります。

## 単位

| 単位 | 意味 |
| --- | --- |
| `px` | ピクセル。画面の点の数 |
| `%` | 親の幅に対する割合 |
| `rem` | 基本の文字サイズの何倍か。`1rem` は通常 16px |

最初は `px` だけで十分です。慣れてきたら `rem` や `%` を使うと、画面の大きさが変わっても崩れにくいページになります。

## まとめ

- 要素はすべて四角い箱で、padding、border、margin の3つの空きを持つ
- `padding` は内側、`margin` は外側の余白
- `border: 太さ 種類 色` で枠線
- `width` で幅、`margin: 0 auto` で中央寄せ
