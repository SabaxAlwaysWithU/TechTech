## 見出しと段落だけでは足りない

レシピのページを思い浮かべてください。材料は箇条書き、手順は番号付き、関連ページへのリンク、完成写真。見出しと段落だけでは表せない部品がいくつも出てきます。

このレッスンでは、よく使う4つの部品を覚えます。リスト、リンク、画像、強調です。

## リスト: ul、ol、li

箇条書きは `ul`(unordered list、順序なしリスト)で、項目1つ1つを `li`(list item)に入れます。

```html
<ul>
  <li>卵</li>
  <li>牛乳</li>
  <li>砂糖</li>
</ul>
```

番号付きにしたいときは `ul` を `ol`(ordered list)に変えるだけです。

```html
<ol>
  <li>卵を割る</li>
  <li>牛乳と砂糖を混ぜる</li>
  <li>焼く</li>
</ol>
```

`li` は必ず `ul` か `ol` の中に入れます。`li` を直接並べるのは誤りです。

## リンク: a

別のページへ飛ぶリンクは `a`(anchor)要素です。飛び先は `href` という**属性**で指定します。

```html
<a href="https://example.com/">例のサイト</a>
```

属性は、開始タグの中に `名前="値"` の形で書く追加情報です。`a` 要素の中身(ここでは「例のサイト」)が、画面上でクリックできる文字になります。

同じサイト内の別のページなら、`href="about.html"` のようにファイル名だけで書けます。

## 画像: img

画像は `img` 要素で表示します。画像ファイルの場所を `src` 属性で、画像の説明を `alt` 属性で指定します。

```html
<img src="cake.jpg" alt="完成したケーキ">
```

`img` には終了タグがありません。中身を持たない要素だからです。

`alt` は、画像が表示できないときや、目の見えない人が読み上げソフトを使うときに使われる説明文です。省略せず、必ず書く習慣をつけてください。

## 強調: strong と em

文章の一部を目立たせたいときは `strong` を使います。ブラウザは太字で表示します。

```html
<p>オーブンは<strong>必ず予熱</strong>してください。</p>
```

もう少し弱い強調には `em`(emphasis)を使います。斜体で表示されます。

「太字にしたいから `strong`」ではなく、「大事だから `strong`」と考えてください。見た目は後でCSSで変えられますが、意味は変えられません。

## 部品を組み合わせる

これらは入れ子にできます。リストの項目にリンクを入れる、段落の中に強調を入れる、といった組み合わせは日常的に使います。

```html
<h1>レシピ</h1>
<p>材料は<strong>3つ</strong>だけです。</p>
<ul>
  <li>卵</li>
  <li>牛乳</li>
  <li><a href="https://example.com/sugar">砂糖</a></li>
</ul>
<img src="cake.jpg" alt="完成したケーキ">
```

## まとめ

- 箇条書きは `ul`、番号付きは `ol`。項目は `li`
- リンクは `a`、飛び先は `href` 属性
- 画像は `img`、場所は `src`、説明は `alt`。終了タグはない
- 強調は `strong`(強い)と `em`(弱い)。意味で選ぶ
