## Webページは「文章に印を付けたもの」

新聞を思い浮かべてください。大きな見出し、小さな見出し、本文。文字の大きさや太さで「これは見出し」「これは本文」と一目で分かります。

Webページも同じです。ブラウザに「ここは見出し」「ここは段落」と教えるために、文章に**印**を付けます。この印の付け方を決めたものが **HTML** です。

HTMLはプログラミング言語ではありません。文章の「役割」を書き添えるための記法です。

## タグと要素

印は `<` と `>` で囲んだ**タグ**で書きます。

```html
<h1>今日の献立</h1>
```

`<h1>` が開始タグ、`</h1>` が終了タグです。終了タグには `/` が付きます。開始タグから終了タグまでをまとめて**要素**と呼びます。「`h1` 要素の中身は『今日の献立』」という言い方をします。

`h1` は "heading 1"、いちばん大きな見出しという意味です。ブラウザは `h1` 要素を大きく太く表示します。

## 見出し: h1〜h6

見出しは `h1` から `h6` まで6段階あります。数字が小さいほど大きな見出しです。

```html
<h1>今日の献立</h1>
<h2>朝</h2>
<h3>トースト</h3>
<h2>昼</h2>
```

`h1` はページに1つだけ、`h2` はその下の章、`h3` はさらにその下の節、というように、本の目次のような階層で使います。「文字を大きくしたいから `h1`」という使い方はしません。大きさはあとでCSSで変えられます。

## 段落: p

本文は `p`(paragraph、段落)要素に入れます。

```html
<h1>今日の献立</h1>
<p>朝はトーストと卵、昼はうどんにしました。</p>
<p>夜はまだ決めていません。</p>
```

`p` 要素は1つにつき1段落です。ブラウザは段落の間に少し空きを入れて表示します。

## 改行と空白は無視される

HTMLでは、文章の中で改行しても、表示上は改行されません。空白をいくつ並べても1つにまとめられます。

```html
<p>この文は
途中で改行していますが、
1行で表示されます。</p>
```

段落を分けたいときは `p` 要素を分けます。段落の中でどうしても改行したいときは `<br>` を使います。`<br>` には終了タグがありません。

## 入れ子

要素の中に要素を入れることができます。これを**入れ子**と言います。

```html
<p>この部分は<strong>とても大事</strong>です。</p>
```

`p` の中に `strong`(強調)が入っています。入れ子にするときは、内側の要素を先に閉じます。`<p><strong>...</p></strong>` のように交差させると正しく表示されません。

## 書くときのコツ

- タグは小文字で書く(`<H1>` でも動くが、`<h1>` が普通)
- 開始タグを書いたら、すぐ終了タグも書いてから中身を入れる。閉じ忘れを防げる
- 入れ子は字下げ(インデント)すると構造が見やすい

## まとめ

- HTMLは文章に「役割の印(タグ)」を付ける記法
- `<タグ>中身</タグ>` で1つの要素。終了タグには `/` が付く
- 見出しは `h1`〜`h6`、段落は `p`
- 改行や連続する空白は表示に反映されない
