## 手紙には封筒がいる

ここまで書いてきたのは、手紙でいえば「本文」だけでした。実際のWebページには、本文を包む封筒のような決まった形があります。ブラウザはその形を見て「これはHTMLのページだ」と理解します。

## 最小のページ

これが、どのWebページにも共通する骨組みです。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <title>今日の献立</title>
  </head>
  <body>
    <h1>今日の献立</h1>
    <p>朝はトーストにしました。</p>
  </body>
</html>
```

上から順に見ていきます。

| 行 | 役割 |
| --- | --- |
| `<!DOCTYPE html>` | 「これはHTMLです」という宣言。必ず1行目に書く |
| `<html lang="ja">` | ページ全体を包む。`lang="ja"` は日本語のページという印 |
| `<head>` | ページの情報。画面には表示されない |
| `<meta charset="UTF-8">` | 文字コードの指定。これがないと日本語が文字化けすることがある |
| `<title>` | ブラウザのタブに出る題名 |
| `<body>` | 画面に表示する中身。これまで書いてきたものは全部ここに入る |

`head` は「ページについての情報」、`body` は「ページの中身」と覚えてください。

練習場のプレビューは、骨組みを省いても表示してくれます。ただし本物のファイルとして保存するときは、必ずこの形で書きます。

## 中身を区切る: header、main、footer

`body` の中が長くなると、どこが何なのか分かりにくくなります。そこで、場所の役割を表すタグで区切ります。

```html
<body>
  <header>
    <h1>さばのレシピ帳</h1>
  </header>
  <main>
    <h2>今日のレシピ</h2>
    <p>卵焼きの作り方です。</p>
  </main>
  <footer>
    <p>© 2026 さば</p>
  </footer>
</body>
```

- `header`: ページの上部。サイト名やロゴ、メニュー
- `main`: ページの本体。1ページに1つだけ
- `footer`: ページの下部。著作権表示や連絡先

このほか、`nav`(メニュー)、`section`(章)、`article`(記事)などもあります。どれも見た目は変わりませんが、「ここは何か」をブラウザや読み上げソフトに伝えられます。

## 意味のないまとまり: div

「特に役割はないが、まとめて扱いたい」ときは `div` を使います。

```html
<div>
  <p>この2つの段落を</p>
  <p>ひとまとめにしたい</p>
</div>
```

`div` 自体には意味がありません。次のレッスンで学ぶCSSで見た目を付けるときの「入れ物」としてよく使います。ただ、`header` や `main` で表せる場所には、そちらを使うのが望ましいです。

## コメント

HTMLの中にメモを残したいときは、コメントを使います。画面には表示されません。

```html
<!-- ここからメニュー -->
<nav>...</nav>
```

## まとめ

- ページは `<!DOCTYPE html>`、`html`、`head`、`body` の骨組みで包む
- `head` にはページの情報(`meta charset`、`title`)、`body` には表示する中身
- `header`、`main`、`footer` で中身の場所を区切る
- 役割のない入れ物は `div`
