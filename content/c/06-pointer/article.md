## 変数には住所がある

OS の分野で、プログラムはメモリの上で動いていると学びました。メモリは、1バイトごとに番号の付いた、長い長い箱の列です。この番号を**アドレス**(住所)といいます。

変数を作ると、メモリのどこかに箱が用意されます。`&` を付けると、その箱のアドレスがわかります。

```c
#include <stdio.h>

int main() {
    int x = 42;
    printf("x の値: %d\n", x);
    printf("x の住所: %p\n", (void *)&x);
    return 0;
}
```

`%p` はアドレスを表示する書式です。`0x506360` のような、16進数の番号が出ます(どんな番号になるかは、実行する環境や、実行するたびに変わります)。

## ポインタ: 住所を入れる変数

アドレスを入れておく変数が**ポインタ**です。

```c
#include <stdio.h>

int main() {
    int x = 42;
    int *p = &x;
    printf("%d\n", *p);
    *p = 100;
    printf("%d\n", x);
    return 0;
}
```

- `int *p` は「`int` の箱の住所を入れる変数 p」の宣言
- `p = &x` で、p に x の住所を入れる(p は x を**指している**、という)
- `*p` は「p が指している先の箱」。読むことも、書き込むこともできる

`*p = 100;` は、p の中身ではなく、p が指している先(つまり x)に 100 を入れます。だから x が 100 に変わります。

```
x:  [ 42 ]  ← 住所 0x506360(例)
p:  [ 0x506360 ] ── 指している ──→ x
```

宣言のときの `*` は「ポインタです」という印、使うときの `*` は「指している先」という意味です。同じ記号でも、役目が違うので注意してください。

## 関数の中から、呼んだ側の変数を書き換える

レッスン「関数」で、引数はコピーで渡るので、関数の中から呼んだ側の変数は書き換えられない、と学びました。でも、**住所を渡せば**、その住所の箱を書き換えられます。

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main() {
    int x = 1;
    int y = 2;
    swap(&x, &y);
    printf("x=%d y=%d\n", x, y);
    return 0;
}
```

`swap(&x, &y)` で、x と y の**住所**を渡します。関数の中の `*a` と `*b` は、main の x と y そのものなので、入れ替えが main に残ります。

この形は、「関数から2つ以上の結果を返したい」ときにも使います。

```c
#include <stdio.h>

void divide(int a, int b, int *q, int *r) {
    *q = a / b;
    *r = a % b;
}

int main() {
    int q;
    int r;
    divide(17, 5, &q, &r);
    printf("17 ÷ 5 = %d 余り %d\n", q, r);
    return 0;
}
```

`return` で返せる値は1つだけなので、結果を入れてほしい箱の住所を渡しておく、というやり方です。キーボードから数を読む `scanf("%d", &x)` に `&` が付くのも、「読んだ数を x の箱に入れて」と住所を渡しているからです。

## 配列とポインタ

配列の名前は、**最初の要素の住所**として使えます。

```c
#include <stdio.h>

int main() {
    int a[3] = {10, 20, 30};
    int *p = a;
    printf("%d %d\n", *p, *(p + 1));
    printf("%d %d\n", p[2], a[2]);
    p++;
    printf("%d\n", *p);
    return 0;
}
```

- `int *p = a;` は `int *p = &a[0];` と同じ
- `p + 1` は「1バイト先」ではなく「**int 1つ分(4バイト)先**」、つまり次の要素の住所
- `a[i]` は、実は `*(a + i)` の短い書き方。だからポインタにも `p[2]` が使える

これで、前のレッスンの2つの謎が解けます。

- **配列を関数に渡すと、元の配列が変わる**: 渡しているのは配列のコピーではなく、最初の要素の住所だから
- **文字列を `==` で比べられない**: `a == b` は、2つの文字列の**住所**が同じかどうかを比べている。中身が同じでも、別の場所にあれば違う、になる

## どこも指していない: NULL

まだどこも指していないポインタには、`NULL` を入れておきます。

```c
#include <stdio.h>

int main() {
    int *p = NULL;
    if (p == NULL) {
        printf("まだ何も指していません\n");
    }
    return 0;
}
```

`NULL` のポインタの先を読み書きする(`*p = 1;`)と、本物の C ではプログラムが落ちます(セグメンテーション違反)。この練習場では「NULL pointer dereference」というエラーで知らせます。

もっと危ないのは、値を入れていないポインタです。`int *p;` だけだと、中にはゴミのような住所が入っていて、`*p = 1;` はどこか知らない場所を書き換えてしまいます。ポインタは、宣言するときに住所か `NULL` を入れる、と決めておきましょう。

## Python や JavaScript では

Python や JavaScript にもポインタのような仕組みはありますが、言語が隠してくれています。リストを関数に渡すと中身を変えられるのは、裏で住所を渡しているからです。C は、それを自分の手で、むき出しのまま扱う言語です。だから速く、だから危ない、のです。

## まとめ

- 変数にはメモリの住所(アドレス)がある。`&x` で x の住所
- ポインタは住所を入れる変数。`int *p = &x;` で x を指し、`*p` で指している先を読み書きする
- 住所を渡せば、関数の中から呼んだ側の変数を書き換えられる(swap、結果を2つ返す)
- 配列の名前は最初の要素の住所。`p + 1` は次の要素。`a[i]` は `*(a + i)`
- どこも指していないポインタには `NULL`。値を入れていないポインタは使わない
