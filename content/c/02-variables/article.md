## 箱の大きさを先に決める

Python では `x = 5` と書くだけで変数ができました。C では、変数を使う前に**型**(どんな種類の値を入れる箱か)を決めて**宣言**します。

```c
#include <stdio.h>

int main() {
    int age = 20;
    double height = 171.5;
    char grade = 'A';
    printf("年齢 %d、身長 %f、評価 %c\n", age, height, grade);
    return 0;
}
```

| 型 | 入れるもの | printf の書式 |
| --- | --- | --- |
| `int` | 整数(…, -1, 0, 1, 2, …) | `%d` |
| `double` | 小数 | `%f`(小数点以下6けた)、`%.2f`(2けた) |
| `char` | 1文字(`'A'` のように ' で囲む) | `%c` |

C が型にうるさいのは、型によって**メモリに用意する箱の大きさ**が決まるからです。箱の大きさは `sizeof` で調べられます。`sizeof` の結果は少し特別な型なので、`(int)` を付けて `%d` で出します。

```c
#include <stdio.h>

int main() {
    printf("int: %d バイト\n", (int)sizeof(int));
    printf("double: %d バイト\n", (int)sizeof(double));
    printf("char: %d バイト\n", (int)sizeof(char));
    return 0;
}
```

`int` は4バイト(32ビット)なので、入るのはおよそ -21億から +21億までです。それを超えると、値がぐるっと回って負の数になってしまいます(**オーバーフロー**)。C は、それをエラーとして教えてくれません。

## 宣言と代入

```c
#include <stdio.h>

int main() {
    int count;
    count = 3;
    count = count + 1;
    int total = count * 100;
    printf("%d 個で %d 円\n", count, total);
    return 0;
}
```

`int count;` で箱を用意し、`count = 3;` で値を入れます(代入)。宣言と同時に入れてもかまいません。

本物の C では、宣言しただけで値を入れていない変数には、**前にそのメモリにあったゴミのような値**が入っています。0 とは限りません。変数は、宣言するときに値を入れる習慣にしましょう(この練習場の picoc では 0 になることが多いですが、本物ではそうはいきません)。

## 整数の割り算

C でいちばんつまずきやすいのが、整数どうしの割り算です。

```c
#include <stdio.h>

int main() {
    printf("%d\n", 7 / 2);
    printf("%d\n", 7 % 2);
    printf("%f\n", 7.0 / 2);
    return 0;
}
```

- `int` どうしの `/` は、**小数点以下を切り捨てた整数**になる(7 / 2 は 3)
- `%` は割り算の**余り**(7 % 2 は 1)
- どちらかが小数(`7.0`)なら、答えも小数になる(3.500000)

変数どうしで小数の答えがほしいときは、片方を `(double)` で小数に変えます。これを**キャスト**といいます。

```c
#include <stdio.h>

int main() {
    int sum = 250;
    int n = 3;
    printf("%d\n", sum / n);
    printf("%.2f\n", (double)sum / n);
    return 0;
}
```

`(double)sum / n` は、まず `sum` を小数の 250.0 にしてから割るので、83.33 になります。`(double)(sum / n)` と書くと、先に整数で割って 83 になってから小数にするので、83.00 になってしまいます。

## 文字は小さな数

`char` の中身は、実は**数**です。文字ごとに番号が決まっていて(ASCII コード)、`'A'` は 65、`'B'` は 66 です。

```c
#include <stdio.h>

int main() {
    char c = 'A';
    printf("%c は %d\n", c, c);
    printf("次の文字は %c\n", c + 1);
    return 0;
}
```

同じ値を `%c` で出すと文字、`%d` で出すと数になります。数なので、`c + 1` で次の文字を作れます。

日本語の1文字は、`char` 1つには入りません(何バイトも使います)。日本語は、次のレッスンで見る「文字列」として扱います。

## printf の書式をもう少し

```c
#include <stdio.h>

int main() {
    printf("[%5d]\n", 42);
    printf("[%-5d]\n", 42);
    printf("[%05d]\n", 42);
    printf("[%.1f]\n", 3.14159);
    printf("100%%\n");
    return 0;
}
```

- `%5d` は5けたの幅で右寄せ、`%-5d` は左寄せ、`%05d` は空いたところを 0 で埋める
- `%.1f` は小数点以下1けた(四捨五入)
- `%` そのものを出すときは `%%`

## まとめ

- 変数は型を決めて宣言する。`int` は整数、`double` は小数、`char` は1文字
- 型ごとに箱の大きさが決まっている(`sizeof`)。`int` の範囲を超えるとオーバーフロー
- 宣言するときに値を入れる。本物の C では、入れていない変数の中身はわからない
- `int` どうしの `/` は切り捨て。`%` は余り。小数がほしいなら `(double)` でキャスト
- `char` の中身は数(`'A'` は 65)。`%c` と `%d` で見え方が変わる
