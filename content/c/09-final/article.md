## 頼まれごと

学校の図書室の先生から、本の貸し出しを記録するプログラムを C で作ってほしいと頼まれました。お願いは5つです。

1. 書名から本を探す
2. 本を貸し出す(貸し出し中なら断る)
3. 今借りられる本が何冊あるか数える
4. いちばん人気の本(貸し出し回数が多い本)を探す
5. 本の一覧を、状態つきで表示する

練習場の5つの課題が、この5つです。どれも「関数を1つ作る」課題で、判定は `main` を確かめ用のものに差し替えて行います。

## 使う知識

| 頼まれごと | 使うもの | レッスン |
| --- | --- | --- |
| 1 書名で探す | `for`、`strcmp` | 配列と文字列 |
| 2 貸し出す | 構造体へのポインタ、`->` | ポインタ、構造体 |
| 3 借りられる本を数える | `for`、`if` | 条件と繰り返し |
| 4 人気の本 | 最大を探す | 配列と文字列、構造体 |
| 5 一覧を表示 | `printf` の書式、`%s` | 変数と型、構造体 |

## 本のデータ

本1冊を、構造体1つで表します。

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char title[32];
    int available;
    int count;
} Book;

void set(Book *b, char *title, int available, int count) {
    strcpy(b->title, title);
    b->available = available;
    b->count = count;
}

int main() {
    Book books[3];
    set(&books[0], "はじめてのC", 1, 12);
    set(&books[1], "星の図鑑", 0, 30);
    set(&books[2], "料理の科学", 1, 5);
    printf("%s は %d 回借りられた\n", books[1].title, books[1].count);
    return 0;
}
```

- `title` は書名(文字列)
- `available` は、今借りられるなら 1、貸し出し中なら 0
- `count` は、これまでに貸し出された回数

この練習場では構造体を `{ }` でまとめて初期化できないので、値を入れる関数 `set` を用意してあります。どの課題の初期状態にも入っています。

## 「見つからない」を返す

課題1のように「番号を返す関数」では、見つからなかったときに何を返すかを決めておく必要があります。番号は 0 以上なので、**-1** を「見つからない」の印にするのが C の定番です。

```c
#include <stdio.h>

int find(int a[], int n, int x) {
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            return i;
        }
    }
    return -1;
}

int main() {
    int a[3] = {5, 8, 2};
    printf("%d %d\n", find(a, 3, 8), find(a, 3, 7));
    return 0;
}
```

見つかった時点で `return` すれば、残りは調べずに抜けられます。`for` が最後まで回りきったら見つからなかったので、ループのあとで `-1` を返します。

## 成功したかどうかを返す

課題2の「貸し出す」は、うまくいくとは限りません。貸し出し中の本は借りられないからです。こういう関数は、**成功なら 1、失敗なら 0** を返し、呼んだ側が `if` で確かめるのが C の流儀です。`malloc` が失敗すると `NULL` を返すのと同じ考え方です。

## 詰まったら

- まず `printf` で途中の値を表示して、思った値になっているか確かめる
- 判定のメッセージには「確かめ用の main(…)で」と、どの確かめで違ったかが出る
- 構造体そのものなら `.`、ポインタなら `->`。エラーが出たら、どちらを使うべきか見直す
- 文字列の比べ方は `strcmp(a, b) == 0`(レッスン「配列と文字列」)
