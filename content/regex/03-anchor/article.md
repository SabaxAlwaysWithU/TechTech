## 一部に一致してしまう問題

郵便番号の入力欄で、正しい形かを確かめたいとします。`\d{3}-\d{4}` で調べると、`100-0001` は OK です。でも、`abc100-0001xyz` も OK になってしまいます。文字列の**どこか一部**に一致すれば、一致したことになるからです。

入力のチェックでは、「**全体が**この形か」を確かめたいはずです。

## ^ は始まり、$ は終わり

`^` は**文字列の始まり**、`$` は**文字列の終わり**という「位置」に一致します。文字そのものには一致しません。

```text
^\d{3}-\d{4}$
```

これは「始まり、数字3つ、ハイフン、数字4つ、終わり」なので、前後に余計な文字があると一致しません。

| パターン | 100-0001 | abc100-0001 | 100-0001xyz |
| --- | --- | --- | --- |
| `\d{3}-\d{4}` | 一致 | 一致(一部) | 一致(一部) |
| `^\d{3}-\d{4}$` | 一致 | 一致しない | 一致しない |

`[^0-9]` の `^`(文字クラスの中の先頭で「以外」)と、ここの `^`(始まり)は、同じ記号でも意味が違うので注意してください。

練習場の「全体が一致するか」の課題では、自動で `^` と `$` を付けたのと同じ調べ方をします。

## \b は単語の区切り

`\b` は、**単語の始まりか終わり**(英数字とそれ以外の境目)という位置に一致します。

```text
パターン: cat
文章:     cat category concatenate   →  3か所とも一致

パターン: \bcat\b
文章:     cat category concatenate   →  最初の cat だけ
```

英語の文章で「単語として出てくるもの」だけを探すときに便利です。日本語の文章には単語の区切り(空白)がないので、`\b` はあまり役に立ちません。

## 入力チェックの例

フォームの入力チェック(JavaScript の分野の「フォームを受け取る」)では、正規表現がよく使われます。

| 確かめたいこと | パターン |
| --- | --- |
| 郵便番号 | `^\d{3}-\d{4}$` |
| 半角数字だけ(1けた以上) | `^\d+$` |
| 英小文字で始まり、英数字が続く8〜16文字のユーザー名 | `^[a-z][a-z0-9]{7,15}$` |
| 「はい」か「いいえ」 | `^(はい\|いいえ)$` |

最後の `|` は「または」で、次のレッスンで見ます。HTML の `<input pattern="\d{3}-\d{4}">` にも正規表現を書けて、ブラウザが自動で全体一致で確かめてくれます。

ただし、正規表現でのチェックは「形」を確かめるだけです。郵便番号として**実在するか**まではわかりません。

## まとめ

- `^` は文字列の始まり、`$` は終わり。両方付けると「全体がこの形か」を確かめられる
- 付けないと、文字列の一部に一致しただけで OK になってしまう
- `\b` は単語の区切り。英語で単語として出てくるものだけを探せる
- 入力チェックでは `^…$` で全体一致。確かめられるのは形だけ
