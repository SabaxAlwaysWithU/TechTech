## 探して、変える

正規表現は、探すだけでなく、**一致した部分を別の文字に置き換える**のにも使えます。エディタの「置換」で正規表現を使えば、何百か所の書き換えが一瞬で済みます。

```text
パターン:   \s+
置き換え:   (空白1つ)
文章:       りんご   みかん      ぶどう
結果:       りんご みかん ぶどう
```

空白が何個続いていても、1つにそろえられます。ふつうの置換では、空白の数ごとに何回もやり直すところです。

## 見せたくない部分を隠す

一致した部分を記号に置き換えれば、個人情報を隠すこともできます。

```text
パターン:   \d{4}-\d{4}
置き換え:   ****-****
文章:       電話 090-1234-5678
結果:       電話 090-****-****
```

ログや画面に出す前に、メールアドレスやカード番号を隠す処理は、こうして正規表現で書かれていることがよくあります。

## $1 でグループを使う

置き換える文字の中に `$1`、`$2` … と書くと、パターンの**グループ1、グループ2 … に一致した文字**がそこに入ります。これを使うと、文字の**並べ替え**ができます。

```text
パターン:   (\d{4})/(\d{2})/(\d{2})
置き換え:   $1年$2月$3日
文章:       2026/11/25
結果:       2026年11月25日
```

```text
パターン:   (\w+)@(\w+)
置き換え:   $2 の $1
文章:       saba@example
結果:       example の saba
```

`$0`(や `$&`)は一致した部分全体です。ここで書いた `$1` は JavaScript やエディタ(VS Code)の書き方で、Python の `re.sub` では `\1` と書きます。記号は違っても、考え方は同じです。

## 書き換えすぎに注意

置き換えは、一致したところを**全部**書き換えます。パターンがゆるいと、変えたくないところまで変わってしまいます。

```text
パターン: cat → dog
文章:     cat category
結果:     dog dogegory   ← category まで変わった
```

`\bcat\b` のように、範囲を絞ってから置き換えます。エディタで大量に置き換えるときは、まず「検索」だけをして、色の付いたところが思ったとおりかを確かめてから置き換えるのが安全です。練習場でも、置き換える前の文章の一致したところに色が付きます。

## まとめ

- 一致した部分を、別の文字に置き換えられる。空白をそろえる、情報を隠す、などに使う
- 置き換える文字の `$1`、`$2` には、グループに一致した文字が入る。並べ替えができる
- Python の re.sub では `\1` と書く
- 置き換えは全部に効く。先に検索して、一致したところを確かめてから置き換える
