## ( ) でかたまりにする

くり返しの記号は、すぐ前の1つにかかるのでした。`ha+` は「h のあとに a が1つ以上」です。「ha」というかたまりをくり返したいときは、`( )` で囲んで**グループ**にします。

```text
(ha)+    →  ha、haha、hahaha に一致
```

## | は「または」

`|` は「**左か右のどちらか**」です。

```text
cat|dog          → cat か dog
(月|火|水)曜日    → 月曜日、火曜日、水曜日
```

`|` は、範囲を ( ) で区切らないと、パターン全体を左右に分けてしまいます。`月|火曜日` は「月」か「火曜日」の意味になるので、`(月|火)曜日` のように囲みます。

## 一致した中から、一部を取り出す

グループには、もう1つ大事な働きがあります。**一致した部分のうち、グループの中だけを取り出せる**ことです。

```text
パターン: (\d{4})-(\d{2})-(\d{2})
文章:     発送日は 2026-11-25 です
一致:     2026-11-25
グループ1: 2026   グループ2: 11   グループ3: 25
```

左から、開きカッコの順に1番、2番、3番…と番号が付きます。プログラムでは、この番号でそれぞれを取り出します。

```text
Python:      m = re.search(r"(\d{4})-(\d{2})-(\d{2})", text)
             m.group(1)  → "2026"
JavaScript:  const m = text.match(/(\d{4})-(\d{2})-(\d{2})/);
             m[1]        → "2026"
```

## 全部取り出す

文章の中の一致を**全部**取り出すこともできます。Python の `re.findall`、JavaScript の `matchAll` などです。

```text
パターン: \d+円
文章:     マウス 2500円、キーボード 6800円
全部:     2500円、6800円
```

値段の数字だけがほしいなら、数字をグループにして `(\d+)円` とし、グループ1を取り出します。「円」が付いている数字だけを探しつつ、取り出すのは数字の部分だけ、ということができます。

練習場の「取り出し」の課題では、一致した部分(または指定したグループ)を全部並べた結果で判定します。

## まとめ

- `( )` でかたまりにすると、くり返しの記号をかたまり全体にかけられる
- `|` は「または」。範囲は `( )` で区切る
- グループは左の開きカッコから1、2、3 … と番号が付き、一致した中からその部分だけを取り出せる
- findall や matchAll で、文章の中の一致を全部取り出せる
