## 「〜のような文字」を探したい

ふつうの検索は、「東京」と打てば「東京」を探します。でも、仕事では「**電話番号のような文字**」「**日付のような文字**」を探したいことがよくあります。電話番号は1つ1つ違うので、決まった文字では探せません。

そこで使うのが**正規表現**です。「数字が3つ、ハイフン、数字が4つ」のような**文字のパターン**を、短い記号で書いて探します。

正規表現は、Python や JavaScript をはじめとするほとんどのプログラミング言語、エディタの検索(VS Code の検索欄の `.*` ボタン)、Linux の `grep` コマンドなど、あちこちで同じように使えます。一度覚えれば、ずっと使える道具です。

## 文字そのもの

いちばん簡単なパターンは、文字そのものです。`cat` は「c、a、t が続いたところ」に一致します。

```text
パターン: cat
文章:     The cat sat on the mat.   →  「cat」に一致
```

練習場では、パターンを打つたびに、一致したところに色が付きます。

## . は「なんでも1文字」

`.`(ドット)は、**どんな文字でも1文字**に一致します。

```text
パターン: c.t
一致する:  cat  cut  c9t  c-t
一致しない: ct(間に1文字ない)  cart(間に2文字)
```

ドットそのもの(「.」という文字)を探したいときは、`\.` と前に `\` を付けます。このように、特別な意味のある記号の前に `\` を付けて「文字そのもの」に戻すことを**エスケープ**といいます。

## [ ] は「この中のどれか1文字」

`[ ]` の中に文字を並べると、**その中のどれか1文字**に一致します。これを**文字クラス**といいます。

| パターン | 意味 | 一致する例 |
| --- | --- | --- |
| `[aeiou]` | a、e、i、o、u のどれか | a、e |
| `gr[ae]y` | gray か grey | gray、grey |
| `[0-9]` | 0 から 9 のどれか(- で範囲) | 3、7 |
| `[a-zA-Z]` | 英字のどれか | b、Q |
| `[^0-9]` | 数字**以外**の1文字(先頭の ^ は「以外」) | x、あ |

よく使う文字クラスには、短い書き方があります。

| 短い書き方 | 意味 | 同じもの |
| --- | --- | --- |
| `\d` | 数字1文字 | `[0-9]` |
| `\w` | 英数字かアンダーバー1文字 | `[a-zA-Z0-9_]` |
| `\s` | 空白1文字(スペース、タブ、改行) | |
| `\D` `\W` `\S` | それぞれの**以外** | |

`\d\d\d` なら「数字が3つ続くところ」です。`03-1234` の中の `123` に一致します。

## まとめ

- 正規表現は、文字のパターンで探す道具。言語やエディタ、grep で共通して使える
- 文字そのものはそのまま書く。`.` はなんでも1文字、`\.` はドットそのもの
- `[abc]` はどれか1文字、`[0-9]` は範囲、`[^…]` は以外
- `\d` は数字、`\w` は英数字、`\s` は空白
