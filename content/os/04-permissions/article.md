## 操作する

レッスン2では見るだけでしたが、ファイルは作ったり、コピーしたり、消したりできます。基本の5つです。

| コマンド | やること | 例 |
| --- | --- | --- |
| `mkdir 名前` | ディレクトリを作る | `mkdir work` |
| `touch 名前` | 空のファイルを作る | `touch memo.txt` |
| `cp 元 先` | コピーする | `cp a.txt work/` |
| `mv 元 先` | 移動する。名前の変更にも使う | `mv a.txt b.txt` |
| `rm 名前` | 消す | `rm old.txt` |

`cp` と `mv` の「先」にディレクトリを指定すると、その中に入ります。`mv a.txt b.txt` のように同じ場所で名前を変えれば、名前の変更になります。

`rm` はディレクトリを消せません。中身ごと消すときは `rm -r 名前` と書きます。`rm` には**ゴミ箱がありません**。消したら戻らないので、打つ前にもう一度名前を見てください。

```sh
mkdir work
touch work/todo.txt
ls work
```

## 権限: 誰が何をできるか

学校のロッカーには鍵があり、自分のロッカーは開けられても、他人のロッカーは開けられません。OSのファイルにも同じ仕組みがあり、**権限**(パーミッション)と言います。

`ls -l` で見てみましょう。

```sh
ls -l
```

```
-rw-r--r-- saba    45 readme.txt
drwxr-xr-x saba  4096 docs
```

左端の10文字が権限です。分けて読みます。

```
d rwx r-x r-x
│ │   │   └ その他の人
│ │   └──── 同じグループの人
│ └──────── 持ち主
└────────── d ならディレクトリ、- ならファイル
```

3文字ずつが「持ち主」「グループ」「その他」の権限で、それぞれ3種類あります。

| 文字 | 意味 | ファイルでは | ディレクトリでは |
| --- | --- | --- | --- |
| `r` | 読める(read) | 中身を見られる | 一覧を見られる |
| `w` | 書ける(write) | 書き換えられる | 中にファイルを作ったり消したりできる |
| `x` | 実行できる(execute) | プログラムとして動かせる | 中に入れる |

`-` はその権限がないことを表します。`rw-r--r--` なら「持ち主は読み書きできる、他の人は読むだけ」です。

## 実行権限: chmod

`script.sh` のような台本ファイルは、中身は文字ですが「プログラムとして実行する」ことができます。ただし `x` の権限がないと実行できません。権限を変えるのが `chmod` です。

```sh
chmod +x script.sh
ls -l script.sh
```

`+x` で実行権限を付け、`-x` で外します。ダウンロードしたプログラムが「実行できない」と言われたら、たいていこれが原因です。

数字で指定する書き方もあります。`r` を 4、`w` を 2、`x` を 1 として足し、持ち主・グループ・その他の順に3桁並べます。`chmod 755` なら `rwxr-xr-x`、`chmod 644` なら `rw-r--r--` です。よく見かけるので、読めるようにしておきましょう。

## 許可がありません

他人のファイルや、OSの大事なファイルを触ろうとすると、「許可がありません」と断られます。

```sh
cat /etc/shadow
```

これはOSがあなたを守っている動作です。間違って設定ファイルを壊したり、他人のデータを見たりできないようになっています。本当に必要なときの方法は、レッスン6で扱います。

## まとめ

- `mkdir`、`touch`、`cp`、`mv`、`rm` でファイルを操作する。`rm` に取り消しはない
- 権限は `ls -l` の左端10文字。持ち主・グループ・その他 × 読む・書く・実行
- `chmod +x` で実行権限を付ける。数字なら 755、644 など
- 「許可がありません」はOSが守ってくれている印
