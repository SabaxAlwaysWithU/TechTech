## 引き出しの中の仕切り

机の引き出しに書類を入れるとき、「仕事」「学校」と仕切りを作り、「学校」の中にさらに「数学」「英語」と仕切りを作ります。探すときは「学校の中の、数学の中の、プリント」とたどります。

OSもディスクの中を同じように整理しています。書類が**ファイル**、仕切りが**ディレクトリ**(フォルダ)です。ディレクトリの中にディレクトリを入れられるので、全体は木が枝分かれしたような形になります。

## ルートとホーム

Linuxでは、いちばん上のディレクトリを**ルート**と呼び、`/` という名前です。すべてのファイルは `/` から枝分かれした先のどこかにあります。

```
/
├── bin/        基本的なコマンド
├── etc/        設定ファイル
├── home/       ユーザーごとの置き場所
│   └── saba/   ← あなたのホーム
├── tmp/        一時ファイル
├── usr/        追加のプログラム
└── var/        ログなど、増えていくデータ
```

ユーザーが自由に使える場所が**ホームディレクトリ**で、`/home/ユーザー名` にあります。ターミナルを開いた直後はここにいます。ホームは `~`(チルダ)という記号でも表せます。

## 今いる場所: pwd と ls

ターミナルは常に「今いるディレクトリ」を持っています。それを表示するのが `pwd` です。

```sh
pwd
```

今いる場所の中身を一覧するのが `ls` です。

```sh
ls
```

名前の最後に `/` が付いているものがディレクトリです。`ls -l` と打つと、権限や持ち主、大きさも見られます(権限はレッスン4で扱います)。

## 移動する: cd

別のディレクトリに移動するのが `cd` です。

```sh
cd docs
ls
```

`docs` の中に入り、その中身が見えます。1つ上に戻るときは `..` を使います。

```sh
cd ..
```

ホームに戻るときは `cd` だけ、または `cd ~` です。

## パス: 場所の書き方

ファイルやディレクトリの場所を表す文字列を**パス**と言います。書き方が2つあります。

- **絶対パス**: `/` から始めて全部書く。`/home/saba/docs/report.txt`。どこにいても同じ意味
- **相対パス**: 今いる場所から見て書く。`docs/report.txt`(今 `/home/saba` にいるとき)。短いが、いる場所で意味が変わる

相対パスでは `.` が「今いる場所」、`..` が「1つ上」を表します。`../photos` は「1つ上に行って、そこの `photos`」です。

## 中身を見る: cat

ファイルの中身を表示するのが `cat` です。

```sh
cat docs/report.txt
```

これは相対パスです。絶対パスで `cat /home/saba/docs/report.txt` と書いても同じです。

## 拡張子

ファイル名の `.txt` や `.jpg` の部分を**拡張子**と言います。「中身の種類」のヒントで、`.txt` なら文章、`.jpg` なら画像、`.sh` ならコマンドの台本です。OSやアプリは拡張子を見て、どのアプリで開くかを決めています。

## まとめ

- ファイルはディレクトリに入れて整理する。全体は `/`(ルート)から始まる木
- 自分の置き場所はホーム `/home/ユーザー名`、記号は `~`
- `pwd` で今いる場所、`ls` で中身、`cd` で移動、`cat` で中身を表示
- パスは絶対(`/` から)と相対(今の場所から)。`..` は1つ上
