## sorted の中では何が起きているか

Python の `sorted` を使えば一瞬で並びますが、中では「どの順で比べて、どう入れ替えるか」という手順が動いています。並べ替えの手順は何十種類も考えられていて、計算量の考え方を学ぶのにぴったりの題材です。このレッスンでは、わかりやすい2つを自分で書きます。

## 選択ソート: いちばん小さいのを選んで前へ

トランプを並べるとき、「残りの中からいちばん小さいカードを選んで、左端に置く」をくり返す方法です。

```python
def selection_sort(items):
    a = list(items)
    n = len(a)
    for i in range(n):
        smallest = i
        for j in range(i + 1, n):
            if a[j] < a[smallest]:
                smallest = j
        a[i], a[smallest] = a[smallest], a[i]
    return a

print(selection_sort([5, 2, 9, 1, 7]))
```

- 外側の `for` で、左から1つずつ「ここに入れる場所」を決める
- 内側の `for` で、残りの中からいちばん小さいものの番号を探す
- `a[i], a[smallest] = a[smallest], a[i]` は、2つの値を入れ替える Python の書き方

最初に `list(items)` で写しを作っているのは、渡されたリストそのものを書き換えないためです。

## 挿入ソート: 手札に1枚ずつ差し込む

トランプを配られて、1枚受け取るたびに、手札の正しい位置に差し込んでいく方法です。

```python
def insertion_sort(items):
    a = list(items)
    for i in range(1, len(a)):
        card = a[i]
        j = i - 1
        while j >= 0 and a[j] > card:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = card
    return a

print(insertion_sort([5, 2, 9, 1, 7]))
```

左側はいつも並んだ状態に保ちます。新しい1枚より大きいものを1つずつ右へずらし、空いた場所に差し込みます。

挿入ソートには、**もともとほとんど並んでいるデータなら、とても速い**という長所があります。ずらす相手がほとんどないので、手間が n 回ほどで済みます。

## どちらも O(n²)

選択ソートは、1つ目を決めるのに n-1 回、2つ目に n-2 回…と比べるので、全部で約 n² / 2 回比べます。`for` が2重になっていて、内側も n に比例して回るアルゴリズムは、たいてい **O(n²)** です。挿入ソートも、ばらばらのデータでは同じく O(n²) です。

| データの数 | 比べる回数(およそ n² / 2) |
| --- | --- |
| 100 | 5,000 |
| 1万 | 5,000万 |
| 100万 | 5,000億 |

100個なら一瞬ですが、100万個では現実的な時間で終わりません。次のレッスンで、もっと速い並べ替えを見ます。

## まとめ

- 選択ソートは、残りからいちばん小さいものを選んで前に置く
- 挿入ソートは、並んだ左側に1つずつ差し込む。ほとんど並んでいるデータに強い
- どちらも for が2重で O(n²)。データが増えると急に遅くなる
- `a[i], a[j] = a[j], a[i]` で入れ替え。`list(items)` で写しを作ってから並べる
