## 同じ答えでも、手順はいくつもある

**アルゴリズム**とは、問題を解くための手順のことです。料理のレシピのようなもので、同じ料理(答え)でも、手順によってかかる時間がまったく違います。

たとえば、名簿から「鈴木さん」を探すとき、1ページ目から順に見ていく方法もあれば、あいうえお順に並んでいるのを利用して、真ん中から開いていく方法もあります。名簿が10人なら差はありませんが、100万人になると、どちらを選ぶかで待ち時間が何万倍も変わります。

## 線形探索: 前から順に見る

いちばん素直な探し方は、**前から1つずつ見ていく**方法です。これを**線形探索**といいます。

```python
def linear_search(items, target):
    for i in range(len(items)):
        if items[i] == target:
            return i
    return -1

names = ["佐藤", "鈴木", "高橋", "田中"]
print(linear_search(names, "高橋"))
print(linear_search(names, "伊藤"))
```

見つかったら番号を、見つからなければ -1 を返します。Python の `リスト.index()` や `in` も、中ではこうして前から順に探しています。

## 手間の数で比べる

アルゴリズムの速さは、秒数ではなく「**手間の数**」(比べた回数など)で比べます。秒数はパソコンの速さで変わりますが、手間の数は変わらないからです。

```python
def linear_search_steps(items, target):
    steps = 0
    for x in items:
        steps += 1
        if x == target:
            return steps
    return steps

data = list(range(1, 1001))
print(linear_search_steps(data, 1))
print(linear_search_steps(data, 1000))
print(linear_search_steps(data, 5000))
```

1000個の中から探すと、運がよければ1回、悪ければ1000回、見つからないときも1000回比べます。

## 計算量: データが増えたら、手間はどう増えるか

大事なのは、「**データが n 個に増えたら、手間はどれくらい増えるか**」です。これを**計算量**といい、O(オー)を使って書きます。

線形探索は、いちばん悪いときに n 回比べるので **O(n)** です。データが10倍になれば、手間も10倍になります。

| 計算量 | 読み方 | n = 1,000 のときの手間 | n = 100万 のとき |
| --- | --- | --- | --- |
| O(1) | いつも同じ | 1 | 1 |
| O(log n) | 対数 | 約10 | 約20 |
| O(n) | 比例 | 1,000 | 100万 |
| O(n log n) | | 約1万 | 約2,000万 |
| O(n²) | 2乗 | 100万 | 1兆 |

O(n²) のアルゴリズムは、データが少ないうちは気になりません。でも、100万件のデータでは1兆回の手間になり、1秒に1億回計算できても3時間近くかかります。このあとのレッスンで、O(log n) や O(n log n) のような速い手順を見ていきます。

## まとめ

- アルゴリズムは問題を解く手順。同じ答えでも、手順で速さが大きく変わる
- 線形探索は前から順に見る。見つからなければ -1
- 速さは秒数ではなく手間の数で比べる。データが n 個のときの手間の増え方が計算量
- 線形探索は O(n)。O(n²) はデータが増えると急に遅くなる
