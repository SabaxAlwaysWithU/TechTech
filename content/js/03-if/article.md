## 「もし〜なら」

「雨なら傘を持つ。そうでなければ持たない」。私たちは毎日こういう判断をしています。

プログラムにも同じことをさせられます。**条件分岐**です。条件によって、実行する命令を変えます。

## if

```js
const temperature = 32;

if (temperature >= 30) {
  console.log("暑いです");
}
```

`if (条件) { ... }` の形です。条件が成り立つときだけ、`{ }` の中が実行されます。`temperature` は 32 なので `32 >= 30` が成り立ち、「暑いです」と表示されます。`temperature` が 20 なら何も表示されません。

`{ }` の中は字下げ(インデント)します。字下げしなくても動きますが、どこからどこまでが `if` の中なのか、一目で分かるようにするためです。

## else: そうでなければ

成り立たないときの処理は `else` に書きます。

```js
const temperature = 20;

if (temperature >= 30) {
  console.log("暑いです");
} else {
  console.log("暑くないです");
}
```

3つ以上に分けたいときは `else if` をつなげます。上から順に調べて、最初に成り立ったところだけが実行されます。

```js
const score = 75;

if (score >= 80) {
  console.log("A");
} else if (score >= 60) {
  console.log("B");
} else {
  console.log("C");
}
```

75 は 80 以上ではないので最初の条件は不成立、60 以上なので2つ目が成立して「B」になります。

## 比較

条件には、2つの値を比べる式を書きます。

| 書き方 | 意味 |
| --- | --- |
| `a === b` | 等しい |
| `a !== b` | 等しくない |
| `a > b` | より大きい |
| `a >= b` | 以上 |
| `a < b` | より小さい |
| `a <= b` | 以下 |

等しいかどうかは `=` を3つ書きます。`=` 1つは代入(入れる)なので、`if (x = 5)` と書くと比較ではなく代入になってしまいます。よくある間違いなので、気をつけてください。

比較の結果は `true`(成り立つ)か `false`(成り立たない)の**真偽値**です。

```js
console.log(5 > 3);
console.log(5 === 3);
```

1行目は `true`、2行目は `false` と表示されます。

## 条件を組み合わせる: && と ||

2つの条件を両方満たすときは `&&`(かつ)、どちらかを満たすときは `||`(または)でつなぎます。

```js
const age = 20;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("入場できます");
}
```

`!` を付けると逆になります。`!hasTicket` は「チケットを持っていない」です。

## 文字列の比較

文字列も `===` で比べられます。

```js
const weather = "雨";

if (weather === "雨") {
  console.log("傘を持っていく");
} else {
  console.log("傘はいらない");
}
```

## まとめ

- `if (条件) { ... }` で、条件が成り立つときだけ実行する
- `else` でそうでないとき、`else if` で3つ以上に分ける
- 等しいは `===`、等しくないは `!==`。`=` 1つは代入
- `&&`(かつ)、`||`(または)、`!`(でない)で条件を組み合わせる
