## レシピの「タレを作る」

レシピに「タレを作る(醤油大さじ2、みりん大さじ1を混ぜる)」と毎回書くのは面倒です。「タレの作り方」を1か所に書いておいて、「ここでタレを作る」と呼び出せば済みます。

プログラムでこれをするのが**関数**です。ひとまとまりの処理に名前を付けておき、名前で呼び出します。

## 関数を作る、呼び出す

```js
function greet() {
  console.log("こんにちは");
  console.log("ようこそ");
}

greet();
greet();
```

`function 名前() { ... }` で関数を作ります(**定義**)。作っただけでは何も起きません。`greet();` と書いたときに `{ }` の中が実行されます(**呼び出し**)。上の例では2回呼んでいるので、4行表示されます。

実は `console.log` も関数です。誰かが作っておいてくれた関数を、私たちは呼び出しているだけです。

## 引数: 関数に値を渡す

「こんにちは、さばさん」「こんにちは、たらさん」のように、呼ぶたびに少し違う動きをさせたいときは、**引数**(ひきすう)で値を渡します。

```js
function greet(name) {
  console.log("こんにちは、" + name + "さん");
}

greet("さば");
greet("たら");
```

カッコの中の `name` が引数です。`greet("さば")` と呼ぶと、`name` に `"さば"` が入った状態で `{ }` が実行されます。

引数はカンマで区切って複数渡せます。

```js
function introduce(name, age) {
  console.log(`${name}さんは${age}歳です`);
}

introduce("さば", 20);
```

## 戻り値: 関数から値を返す

関数は、計算した結果を呼び出した側に**返す**ことができます。`return` を使います。

```js
function add(a, b) {
  return a + b;
}

const result = add(3, 4);
console.log(result);
```

`add(3, 4)` は `7` という値になり、それが `result` に入ります。`console.log(add(3, 4))` のように直接表示することもできます。

`return` を実行すると、関数はそこで終わります。`return` のあとに書いた命令は実行されません。これを使って、条件に合ったら早めに返す書き方もよくします。

```js
function isAdult(age) {
  if (age >= 18) {
    return true;
  }
  return false;
}
```

`return` のない関数は `undefined` を返します。`console.log` が表示するのは出力欄であって、値を返しているわけではないので、`console.log` と `return` を混同しないようにしてください。

## 関数を使う理由

- **同じ処理を1か所にまとめられる**: 直すときも1か所で済む
- **名前が説明になる**: `calcTax(price)` と書いてあれば、中を読まなくても何をするか分かる
- **分けて考えられる**: 大きなプログラムを、小さな関数の組み合わせにできる

長いプログラムを書くときは、「この部分は関数にできないか」と考える癖をつけてください。

## アロー関数

関数には短い書き方もあります。

```js
const add = (a, b) => a + b;
console.log(add(3, 4));
```

`(引数) => 式` の形で、`function` と `return` を省略できます。見かけることが多いので、読めるようにしておいてください。最初のうちは `function` で書いて構いません。

## まとめ

- `function 名前(引数) { ... }` で関数を作り、`名前(値)` で呼び出す
- 引数で関数に値を渡し、`return` で結果を返す
- `return` した時点で関数は終わる
- 同じ処理は関数にまとめる
