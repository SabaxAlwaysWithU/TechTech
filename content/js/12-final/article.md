## 頼まれごと

ネットショップの開発チームに入りました。最初の仕事は、買い物かご(カート)まわりの部品づくりです。

1. カートに入っている商品の合計金額を出す
2. 合計が 5000 円以上なら送料無料、それ未満なら送料 500 円を足す
3. 商品の一覧から、在庫があるものの名前だけを取り出す
4. お店の API から商品一覧を取ってきて、カテゴリごとの商品数を数える
5. API に注文を送り、うまくいったか、だめなら理由を、文章にして返す

練習場の5つの課題が、この5つの部品です。どれも「関数を1つ作る」課題で、判定は関数を呼んだ結果で行います。

## カートのデータ

カートは「オブジェクトの配列」です。1つの商品が1つのオブジェクトで、価格(`price`)と個数(`qty`)を持っています。

```js
const cart = [
  { name: "マウス", price: 2500, qty: 2 },
  { name: "USBメモリ", price: 1800, qty: 1 },
];
```

この場合の合計は 2500 × 2 + 1800 × 1 = 6800 円です。

## 小さな関数を組み合わせる

課題2は、課題1で作った合計の関数を中で呼ぶと短く書けます。

```js
function cartTotal(items) {
  let total = 0;
  for (const item of items) {
    total += item.price * item.qty;
  }
  return total;
}

console.log(cartTotal([{ name: "マウス", price: 2500, qty: 2 }]));
```

1つの関数に全部を詰め込まず、「合計を出す」「送料を決める」のように役割ごとに分けると、それぞれを確かめやすくなります。実際の開発でも、この分け方が基本です。

## API を使う課題

課題4と5では、前に使った練習用の API(`https://shop.example`)を使います。

- `GET /api/products`: 商品の一覧。各商品は `{ id, name, category, price, stock }`
- `POST /api/orders`: 注文。送るのは `{ productId, quantity }`。成功すると 201 で `{ name, quantity, total, ... }`、失敗すると 400 や 404 で `{ error }` が返る

`fetch` の返事は、`await response.json()` で中身を取り出すこと、404 や 400 でもエラーにはならないので `response.ok` で確かめること、の2つを思い出してください。
