## 料理のレシピと同じ

レシピは「卵を割る」「混ぜる」「焼く」のように、やることを順番に書いたものです。読んだ人がその通りに動けば、料理ができあがります。

プログラムも同じです。コンピュータにやってほしいことを、順番に書いたものがプログラムです。違いは、読むのが人ではなくコンピュータだということ。コンピュータは書いてある通りにしか動かないので、書き方には決まりがあります。その決まりが**プログラミング言語**で、この分野では **JavaScript** を使います。

JavaScriptは、Webページを動かすために作られた言語です。ブラウザがあればすぐ動かせるので、最初の言語として向いています。

## 画面に表示する: console.log

最初のプログラムです。

```js
console.log("こんにちは");
```

`console.log(...)` は「カッコの中身を出力に表示して」という命令です。練習場で実行すると、右の出力欄に「こんにちは」と出ます。

1行の終わりには `;`(セミコロン)を付けます。「ここで1つの命令が終わり」という印です。

命令は上から順に実行されます。

```js
console.log("おはよう");
console.log("こんにちは");
console.log("こんばんは");
```

## 文字列と数値

`"こんにちは"` のように `"` で囲んだものを**文字列**と言います。文字の並びです。`'`(シングルクォート)で囲んでも同じです。

数は囲みません。

```js
console.log(3 + 5);
```

これは `8` と表示されます。`3 + 5` が先に計算されて、その結果が表示されるからです。計算には `+`、`-`、`*`(かけ算)、`/`(わり算)が使えます。

引用符で囲むかどうかで、意味が変わります。

```js
console.log(3 + 5);
console.log("3 + 5");
```

1行目は `8`、2行目は `3 + 5` という文字がそのまま出ます。囲むと「計算式」ではなく「ただの文字」になるからです。

## 文字列をつなぐ

文字列同士を `+` でつなぐと、くっつきます。

```js
console.log("こんにちは、" + "さばさん");
```

結果は `こんにちは、さばさん` です。文字列と数を `+` でつなぐと、数も文字として扱われます。

```js
console.log("合計は" + 8 + "円です");
```

## コメント

`//` から行の終わりまでは**コメント**で、実行されません。自分や他の人のためのメモです。

```js
// これはメモ。実行されない
console.log("これは実行される");
```

コードの中で「ここで何をしているか」を書いておくと、あとで読み返したときに助かります。

## エラーを恐れない

書き方を間違えると、コンピュータはエラーを出して止まります。たとえば引用符を閉じ忘れたり、カッコを忘れたり。

```js
console.log("閉じ忘れ);
```

エラーは「ここが分からない」という知らせです。練習場では日本語の補足が付くので、落ち着いて読んで直してください。プログラミングは、エラーを直す作業の連続です。

## まとめ

- プログラムは、コンピュータにやってほしいことを順番に書いたもの
- `console.log(...)` で出力に表示する。行末に `;`
- `"` で囲むと文字列、囲まないと数値。数値は計算される
- `+` で文字列をつなげる
- `//` から行末まではコメント
