## 値が増えると変数では足りない

買い物リストに10品あるとき、`item1`、`item2`、…と10個の変数を作るのは大変です。「リストをまとめて1つの変数に入れたい」。それをかなえるのが**配列**です。

もう1つ、「商品の名前と価格と在庫数」のように、1つのものに関する複数の情報をまとめたいこともあります。それが**オブジェクト**です。

## 配列: 順番に並んだ値

```js
const fruits = ["りんご", "バナナ", "みかん"];
```

`[ ]` の中にカンマ区切りで値を並べます。中身を取り出すには、何番目かを `[ ]` で指定します。番号は**0から**始まります。

```js
console.log(fruits[0]);
console.log(fruits[2]);
```

1行目は「りんご」、2行目は「みかん」です。最初が0番なので、3つ目は2番です。慣れるまで間違えやすいところです。

配列の長さ(要素の数)は `.length` で分かります。

```js
console.log(fruits.length);
```

## 配列に足す、変える

末尾に足すのは `.push()` です。

```js
const fruits = ["りんご", "バナナ"];
fruits.push("みかん");
console.log(fruits);
```

`const` で作った配列でも、中身の追加や変更はできます。`const` が禁じているのは「別の配列に入れ替える」ことだけです。

中身を変えるときは、番号を指定して代入します。

```js
fruits[0] = "いちご";
```

## 配列と繰り返し

配列は `for...of` と組み合わせると力を発揮します。合計を求める例です。

```js
const prices = [120, 300, 80];
let total = 0;
for (const price of prices) {
  total += price;
}
console.log(total);
```

何番目かも使いたいときは、普通の `for` で `i` を 0 から `length - 1` まで回します。

```js
for (let i = 0; i < prices.length; i++) {
  console.log(`${i + 1}番目: ${prices[i]}円`);
}
```

## オブジェクト: 名前の付いた値の集まり

```js
const product = {
  name: "マウス",
  price: 2500,
  stock: 10,
};
```

`{ }` の中に `名前: 値` をカンマで並べます。この名前を**プロパティ**と言います。取り出すときは `.` を使います。

```js
console.log(product.name);
console.log(product.price * 2);
```

変えるときも `.` で代入します。

```js
product.stock = 9;
```

配列が「番号で取り出す」なら、オブジェクトは「名前で取り出す」です。順番に意味があるなら配列、項目に名前があるならオブジェクトを使います。

## 配列の中にオブジェクト

実際のプログラムでは、この2つを組み合わせます。商品の一覧は「オブジェクトの配列」です。

```js
const products = [
  { name: "マウス", price: 2500 },
  { name: "キーボード", price: 6800 },
  { name: "モニター", price: 32000 },
];

for (const p of products) {
  console.log(`${p.name}: ${p.price}円`);
}
```

`p` に1つずつオブジェクトが入り、`p.name` で名前が取り出せます。SQL分野で見た「表」は、まさにこの形です。1行が1つのオブジェクト、表全体が配列です。

## まとめ

- 配列は `[値, 値, ...]`。`配列[番号]` で取り出す。番号は0から
- `.length` で個数、`.push(値)` で末尾に追加
- オブジェクトは `{ 名前: 値, ... }`。`オブジェクト.名前` で取り出す
- 「オブジェクトの配列」で一覧を表せる。`for...of` で1つずつ処理する
