## 名前の付いた箱

買い物のメモに「りんご 3個」と書いておけば、あとで「りんごは何個だっけ」と思ったときに見返せます。

プログラムでも同じことをします。値に名前を付けて覚えておく仕組みが**変数**です。名前の付いた箱に値を入れておき、あとで名前で取り出します。

## 変数を作る: let

```js
let count = 3;
console.log(count);
```

`let 名前 = 値;` で変数を作ります。これを**宣言**と言います。以後、`count` と書くと `3` として扱われます。

値はあとから変えられます。変えるときは `let` を付けません。

```js
let count = 3;
count = 5;
console.log(count);
```

結果は `5` です。`count = 5` は「`count` に `5` を入れ直す」という意味で、これを**代入**と言います。

`=` は「等しい」ではなく「右の値を左に入れる」です。数学と違うので注意してください。`count = count + 1` は「今の `count` に1を足した値を、`count` に入れ直す」で、結果 `count` は1増えます。

## 変えない変数: const

あとから変えない値には `const` を使います。

```js
const taxRate = 0.1;
console.log(100 * taxRate);
```

`const` の変数に代入しようとするとエラーになります。「うっかり変えてしまった」を防げるので、迷ったら `const`、変える必要が出たら `let` にします。

## 名前の付け方

- 英字で始める。`count`、`userName`、`price2`
- 2語以上は2語目の頭を大文字にする(`userName`)。これを**キャメルケース**と言う
- 中身が分かる名前にする。`a` より `count`、`x` より `price`

日本語も使えますが、英語で付けるのが普通です。

## 文字列の組み立て

変数を文字列につなぐときも `+` が使えます。

```js
const name = "さば";
console.log("こんにちは、" + name + "さん");
```

ただ `+` が増えると読みにくくなります。そこで**テンプレートリテラル**という書き方があります。

```js
const name = "さば";
const age = 20;
console.log(`${name}さんは${age}歳です`);
```

バッククォート `` ` `` で囲み、中に `${変数}` を書くと、その部分が変数の値に置き換わります。`${}` の中には計算式も書けます。

## 型

変数には、文字列、数値のほかに、いくつかの種類の値が入ります。この種類を**型**と言います。

| 型 | 例 |
| --- | --- |
| 文字列 | `"こんにちは"` |
| 数値 | `3`、`0.5`、`-10` |
| 真偽値 | `true`、`false` |
| 未定義 | `undefined`(まだ値が入っていない) |

真偽値は次のレッスンの条件分岐で使います。`undefined` は、`let x;` のように値を入れずに宣言したときに入っています。

## まとめ

- `let 名前 = 値;` で変数を作る。`名前 = 値;` で入れ直す
- 変えない値は `const`。迷ったら `const`
- `=` は「右を左に入れる」。`count = count + 1` で1増える
- `` `${変数}` `` で文字列に変数を埋め込める
