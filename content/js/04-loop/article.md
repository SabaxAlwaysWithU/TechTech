## 同じことを100回書きたくない

「1から100までの数を表示する」プログラムを書くとします。`console.log(1);` から `console.log(100);` まで100行書けばできますが、書きたくありませんし、1000までなら無理です。

コンピュータは同じことを繰り返すのが得意です。その指示を出すのが**繰り返し**(ループ)です。

## for

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

これで 1 から 5 までが表示されます。カッコの中は3つの部分に分かれています。

1. `let i = 1`: 最初に1回だけ実行。変数 `i` を 1 で作る
2. `i <= 5`: 毎回、繰り返す前に調べる。成り立つ間だけ繰り返す
3. `i++`: `{ }` を1回実行するたびに実行。`i` を1増やす(`i = i + 1` と同じ)

流れは「`i` が 1 → `{ }` を実行 → `i` が 2 → `{ }` を実行 → … → `i` が 6 になると条件が不成立で終わり」です。

変数名の `i` は慣習で、何回目かを数える変数によく使います。

`i` は `{ }` の中で使えるので、「3の倍数だけ表示」のようなこともできます。

```js
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) {
    console.log(i);
  }
}
```

## 合計を求める

繰り返しと変数を組み合わせると、合計が計算できます。

```js
let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum = sum + i;
}
console.log(sum);
```

`sum` を 0 から始めて、毎回 `i` を足していきます。終わったときの `sum` が 1 から 10 の合計、55 です。

`sum = sum + i` は `sum += i` と短く書けます。

## while

回数が決まっていないときは `while` を使います。条件が成り立つ間、繰り返します。

```js
let money = 1000;
let years = 0;
while (money < 2000) {
  money = money * 1.1;
  years++;
}
console.log(years);
```

「お金が2000を超えるまで、毎年1.1倍にする」で、何年かかるかを数えています。

`while` で気をつけるのは**無限ループ**です。条件がいつまでも成り立つと、プログラムが止まらなくなります。`{ }` の中で、条件に関わる変数がちゃんと変わっているか確認してください。練習場では3秒で打ち切られます。

## 配列を繰り返す: for...of

いくつかの値をまとめて持つのが**配列**です(次のレッスンで詳しく学びます)。

```js
const fruits = ["りんご", "バナナ", "みかん"];
```

配列の中身を順番に取り出すには `for...of` を使います。

```js
const fruits = ["りんご", "バナナ", "みかん"];
for (const fruit of fruits) {
  console.log(fruit);
}
```

`fruit` に「りんご」「バナナ」「みかん」が順に入り、3回繰り返されます。回数を数える変数がいらないので、配列を全部見るときはこの形が楽です。

## まとめ

- `for (let i = 1; i <= n; i++) { ... }` で n 回繰り返す
- 繰り返しの外で変数を作り、中で足していくと合計が出せる
- 回数が決まっていないときは `while (条件) { ... }`。無限ループに注意
- 配列の中身を順に見るときは `for (const x of 配列) { ... }`
