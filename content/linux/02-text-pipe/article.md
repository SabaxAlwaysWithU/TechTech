## 小さな道具を組み合わせる

Linux のコマンドは、1つ1つが小さな仕事しかしません。`grep` は探すだけ、`sort` は並べるだけ、`wc` は数えるだけ。その代わり、**つなげて使う**ことができます。この「小さな道具を組み合わせる」考え方が、Linux(と、その元になった UNIX)の真骨頂です。

つなぐ記号が `|`(**パイプ**)です。左のコマンドの出力が、右のコマンドの入力に流れ込みます。

```sh
ps | grep firefox
```

`ps` が出したプロセスの一覧を、`grep` が受け取り、`firefox` を含む行だけを残します。水道管(パイプ)をつなぐように、データが左から右へ流れていきます。

## grep: 探す

ファイルやパイプの中から、ある文字を含む行だけを取り出します。

```sh
grep warning /var/log/system.log
```

ログの中から警告だけを探す、というのがいちばんよくある使い方です。よく使うオプションは3つ。

| オプション | 意味 |
| --- | --- |
| `-i` | 大文字と小文字を区別しない |
| `-v` | その文字を**含まない**行を出す |
| `-c` | 行を出す代わりに、何行あったかを数える |

## head と tail: 先頭と末尾

```sh
head -n 3 /var/log/system.log
tail -n 2 /var/log/system.log
```

`head` は先頭の数行、`tail` は末尾の数行です。ログは下に追記されていくので、**最新の出来事を見るには `tail`** です。本物の Linux では `tail -f` で、増えていくログを見張り続けることもできます。

## wc: 数える

```sh
wc -l /etc/passwd
```

`-l` で行数を数えます。`/etc/passwd` は1行1ユーザーなので、ユーザーの人数が分かります。

## sort: 並べる

```sh
sort -r ファイル
```

そのまま使うと辞書順、`-n` で数の順、`-r` で逆順です。`-h` は `16G` や `4.0K` のような「人間向けの大きさ」を正しく並べます(レッスン5で使います)。

## つなげてみる

ここからが本番です。道具をつなぐと、1つのコマンドではできないことができます。

```sh
ps | grep saba | wc -l
```

「saba さんのプロセスはいくつ動いている?」が1行で分かります。

```sh
grep -v kernel /var/log/system.log | tail -n 2
```

「カーネル以外のログのうち、最新の2行」。

```sh
ls /bin | sort -r | head -n 3
```

「/bin のコマンドを逆順に並べた最初の3つ」。

どれも、左から順に「出して → 絞って → 数える(並べる)」と読めば意味が分かります。長いパイプも、1段ずつ足して結果を見ながら作るのがコツです。

## > との違い

OS分野で出てきた `>` は「出力を**ファイル**に書く」、`|` は「出力を**次のコマンド**に渡す」です。組み合わせて、`grep warning /var/log/system.log > warnings.txt` のように、絞った結果だけを保存することもできます。

## まとめ

- `|` で左の出力を右の入力に流す。小さな道具を組み合わせるのが Linux 流
- `grep` で探す(`-i`、`-v`、`-c`)、`head` / `tail` で先頭 / 末尾、`wc -l` で数える、`sort` で並べる
- 最新のログは `tail`
- 長いパイプは1段ずつ足して作る
