## 世界のサーバーのほとんど

あなたが毎日見ている Webサイトの裏側では、ほとんどの場合 **Linux** が動いています。Google も Amazon も、このサイト TechTech を配っている GitHub も、サーバーの多くは Linux です。スマートフォンの Android も、家のルーターも、テレビも、中身は Linux であることが多いです。

OS分野で「OS は管理人」と説明しました。Linux はその管理人の1人で、特に**サーバーの管理人**として圧倒的に選ばれています。

## 理由: 無料で、中身が公開されている

Linux は 1991年に、フィンランドの大学生だったリーナス・トーバルズが趣味で作り始めました。最初から**中身(ソースコード)を公開し、誰でも無料で使い、直し、配ってよい**という形で広まりました。これを**オープンソース**と言います。

- 無料なので、サーバーを1000台並べても OS 代がかからない
- 中身が見えるので、問題があれば自分で調べて直せる
- 世界中の人が改良しているので、安定していて速い
- 画面(GUI)なしでも動き、軽い

## カーネルとディストリビューション

厳密には、Linux は OS の中心部分、**カーネル**だけの名前です。カーネルだけでは、コマンドもパッケージ管理も設定画面もなく、使えません。

そこで、カーネルに必要な道具一式をまとめて配っているものがあり、これを**ディストリビューション**(略してディストロ)と呼びます。同じカーネルを使った、別々の「製品」のようなものです。

| ディストリビューション | 特徴 |
| --- | --- |
| **Ubuntu** | いちばん人気。情報が多く、初心者向け。サーバーにもデスクトップにも |
| **Debian** | Ubuntu の元になった老舗。安定重視 |
| **Red Hat Enterprise Linux / AlmaLinux / Rocky Linux** | 企業向け。会社のサーバーで多い |
| **Alpine Linux** | とても小さい。Docker の中でよく使われる |
| **Arch Linux** | 自分で組み立てる上級者向け |

ディストリビューションによって、ソフトを入れるコマンド(`apt` か `dnf` か)や設定ファイルの場所が少しずつ違います。この分野では、いちばん多い **Ubuntu** の流儀で説明します。

## 自分のディストリビューションを調べる

```sh
uname -a
```

カーネルの名前とバージョンが出ます。ディストリビューションは `/etc/os-release` に書いてあります。

```sh
cat /etc/os-release
```

## Linux を触る方法

自分のパソコンが Windows や Mac でも、Linux は使えます。

- **WSL**(Windows Subsystem for Linux): Windows の中で Ubuntu が動く。Windows ならまずこれ
- **Mac のターミナル**: Mac は Linux ではないが、親戚の UNIX なので、ほとんどのコマンドが同じ
- **クラウドや VPS**: Linux のサーバーを1台借りて、SSH でつなぐ(レッスン6)
- **Raspberry Pi**: 数千円の小さなコンピュータ。電子工作にも

## 「すべてはファイル」

Linux の考え方で有名なのが「**すべてはファイル**」です。設定は `/etc` の下の文字のファイル、ログは `/var/log` の下の文字のファイル。キーボードやディスクのような装置まで `/dev` の下にファイルとして見えます。

だから Linux では、ファイルを読む・探す・書き換える道具が、そのままシステムを調べて直す道具になります。次のレッスンで、その道具を覚えます。

## まとめ

- Linux はサーバーの OS の大多数。無料でオープンソース
- 厳密には Linux はカーネル。道具一式を付けたものがディストリビューション(Ubuntu など)
- Windows なら WSL で、すぐに Ubuntu を試せる
- 設定もログも文字のファイル。ファイルを扱う道具がそのまま管理の道具になる
